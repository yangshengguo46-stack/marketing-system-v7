# 完整课程后的创作与Lead判断首轮试用

2026-09-09，用户批准“提炼成做法→实际执行→检验效果→固化复用”，并要求Lead判断本身接受检验。本轮在原分支与目录继续，保留既有工程修改、完整课程、旧故事和全部失败记录。

**目前最重要的结果：课程可被落实为执行方法，但本轮没有证明这些通用步骤能让GPT-6写得更好或判断得更准。** 因此交付可回源的候选工作包，暂不安装自动触发Skill，不把资料整理完成当成业务能力通过。

## 这轮怎么执行

[计划](plan.md)和[运行条件](run-conditions.json)列明范围。共同题面在写作前固定；候选方法及诊断参考在相应判断前冻结；四稿首次交付在匿名审读前冻结。模型均按指定读范围工作，文件系统共享，不能声称OS隔离或完整模型请求审计。作者与编辑实际读文件名单保留在各输出中。

原生课程试作使用既有 `native_client.py` 与 `codex-app-server`，模型 `glm-5-2-260617`；自动记忆的三个开关均关，沿既有 `marketing_work` 保存与返工。它与GPT-6新题试写是两个不同实验，不用跨模型结果证明课程方法因果增益。根Lead传递独立读稿反馈并处理实际来源截断，干预如实记录。

方法来源与操作要求区分：

- [Lead方法来源核读](lead-method-source-review.md)

## 采用决定与仍未解决的问题

1. **保留候选参考，不固化为默认必经Skill。** 冻结版参与测试后不回写，避免用改过的方法解释旧结果。课件按需要解释具体难题；模型已经能直接完成的部分不增加步骤。对强模型的增益必须由新证据支持，不能靠“还没出现AGI”保证。
2. **Lead职责保留，但判断要落到正文。** 本轮独立Lead确实发现了原生初稿问题；这不证明没有方法的GPT-6就发现不了，更不等于稳定的人类编导水平。意见里的时间压力被正确留作取舍，不能仅因四点到六点半就判定时程矛盾。
3. **真实业务能力仍未获证。** 没有真人编导/目标受众反馈、采用、拍摄、传播或招募数据；也没有新ContentPackage或视频。本轮固定虚构题没有测试互联网取材带来的创意增益，不能代替真实案例研究。
4. **下一项应围绕具体缺口。** 优先检验“得到新的可靠材料后，能否产生原来想不到、又适合主体的表达”，或实际复杂作品中已暴露的约束/返工问题。继续完整作品、独立强模型对照和反馈证据，不继续堆通用写作步骤，不让用户上课或培养Agent。

没有新运行时、知识库平台、评审服务、固定多Agent组织或产品代码变更。原分支继续，未提交、合并或推送。本页是这次研发试用的记录，不是用户使用产品的学习流程。
