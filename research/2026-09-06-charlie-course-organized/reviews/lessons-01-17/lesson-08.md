## 前课材料怎样续用：保留案例版本

本课开头回顾此前每人写的千字、八项故事，并再次明确它是梗概；第7课的五关键事件与八项发展表也直接续用。**本课结尾的实际作业改用老师刚讲过的警察案例，不要求继续自选故事。**

警察案例有两个可辨认的版本，不能拼成一个无矛盾稿：

| 版本 | 来源与动机 | 此后怎样使用 |
|---|---|---|
| 第3课老师临时构想 | p8 07:13–11:13：女儿已经去世，警察因未能保护而内疚，希望因公殉职后继续保护她。 | 用于演示把吸引人的身份定语合理化，并逐项建立八要素。 |
| 本课采用课代表改写版 | p16 02:14–02:47：“我们以课代表那个”“最后改出来的那个例子”；妻女仍在，想用殉职抚恤金留钱给她们。原字幕[02:16](frames/p016-0136.jpg)、[02:19](frames/p016-0139.jpg)已核。 | 本课继续做十序列：从失职协警、家庭疏离和缺钱开始，最后发展为承担责任、获得女儿认可。老师在此基础上继续现场修改；课代表原稿本身未展示。 |

## 十序列怎样用在本课案例里

功能主要见p15 18:10–25:20，板书见[25:15](frames/p015-1515.jpg)；八项纵轴见[38:10](frames/p015-2290.jpg)。下表按老师最后采用或暂定的课堂方案整理，不代表另有一份已经定稿的剧本。

| 序列 | 原课功能 | 课堂警察案例及定位 |
|---|---|---|
| 开场 | 交代主角与环境，并引发观看兴趣。 | 夜摊独饮，旁边闹事他不管；对讲机响后观众才知道其身份，他仍关机喝酒。p16 05:16–10:07；p17 15:37–17:47重排信息揭示。 |
| 切入 | 延续人物信息，铺垫激励事件。 | 宿醉去前妻家，家庭位置已被替代；女儿要艺术院校学费，他拿不出。p16 10:08–16:55。 |
| 激励 | 核心问题发端。 | 回警局被要求给牺牲者捐款，抱怨中听到抚恤金，于是萌生殉职留钱念头。p16 16:58–20:46。 |
| 进展 | 主角的一次动作／无效尝试。 | 多次求殉职却意外救人、制止坏事；最后一次重大事件带来表彰。p16 20:47–25:34；p17 21:02–22:13。 |
| 转折 | 一个重要因素在方向或程度上发生变化。 | 协警转正、被看作英雄，获得短暂荣誉；核心困境仍未解决。p16 22:36–26:56；p17 22:14–24:29。 |
| 再转 | 因变化调整策略、放手一搏。 | 妻女仍拒绝他，开场放任的坏人又酿严重后果；他意识到“英雄”尚未变成真正担当，转而调查和追捕。p17 00:03–07:38。 |
| 危机 | 最大考验／对手最强攻势。 | 主角准备以命解决罪犯问题，自己也陷入生命危险；观众此时希望他活。p17 07:39–08:42。 |
| 导入 | 增强危机到解决之间的情绪强度。 | 对手提前知道他要来，加上自身失误形成时间压力；从外部对手与生死问题两面加压。p17 08:44–10:58。 |
| 高潮 | 核心问题得到解决。 | 主角在强弱悬殊的对抗中作最后行动，兑现此前责任与生死选择。p17 10:59–12:08；28:41–29:13。 |
| 结局 | 给观众情绪一个落点。 | 比较牺牲与生还版本；暂用医院醒来、听到女儿向外夸耀父亲，继续装昏迷并微笑的结尾。p17 12:14–15:31、29:13–29:47。 |

## 现场修改：改了什么，影响了什么

| 输入／初想 | 老师的修改 | 对后续的影响与证据 |
|---|---|---|
| 转折后“升职加薪”。 | 删去加薪，先给表彰、荣誉，再发展为转正。 | 钱的问题未被过早解决；荣誉成为“虚假胜利”，为后面被家庭现实击破留下空间。p16 22:36–23:36。 |
| 只有一次无效尝试，随即表彰。 | 增加多次尝试，把较大的事件放到后面。 | 进展有积累，获得表彰更有依据；也说明一个序列可以多场。p16 23:39–25:34。 |
| 得到表彰后一味上扬。 | 回收开场放任的闹事者，让其再次酿事；妻女也未因荣誉立刻接纳他。 | 将人物打击和内疚连到此前自身行为，逼出策略与欲望变化。p16 25:35起；p17 00:03–07:38、24:30–27:33。 |
| 突然听到抚恤金就动殉职念头，可能显得突兀。 | 回到切入阶段加强打击，必要时先埋短暂求死念头。 | 让后来的募捐信息成为进一步触发，而不是无来由的转向。p17 20:02–21:01；这是老师回看后提出的备选补法。 |
| 只写“虚假胜利”。 | 加同事态度变化、被邀请和正式警员聚餐等事。 | 把身份变化变为能看见的待遇，随后家庭现实才形成落差。p17 22:34–24:29。 |

## 老师明确布置的作业

**用本课讲过的“想殉职的警察”故事，自己把十个关节写成一个大纲。** 不另自选创意；采用本课抚恤金版及老师的十序列演示作为材料，具体场面可以继续想办法完成。

- p17 31:46–31:58，原ASR：“布置的作业”“你也不用自己创作了，你就把我说的这个一个将要殉职的警察这10个关节自己去写一下”“写一个大纲”。其中31:47原字幕核为[“布置个作业”](frames/p017-1907.jpg)，31:49核为[“你也不用自己创作了”](frames/p017-1909.jpg)，31:57核为[“写一个大纲”](frames/p017-1917.jpg)。
- p17 31:59–32:12，ASR：“十个序列不是只有十场戏啊，是十件大事儿”“多次尝试的时候那就是好多场戏呢”。[32:02原字幕](frames/p017-1922.jpg)已核。
- p17 32:12–32:57进一步示范：回警局可先挨批、跟同事互动、试图躲捐款再被发现；每个关节可能多场，不能一句“回来捐款”带过。
- p17 32:59–33:02，ASR：“写写出一个大纲，就写这个故事”。[33:01原字幕](frames/p017-1981.jpg)已核。
- **交付要求**：一个大纲，以十个主要事件组织、每个事件按需要展开多场，内容应能化为画面和声音。本课开头介绍大纲通常约一两万字（p15 01:03–01:06），但此次布置没有明确字数、文件格式、期限或提交入口。
- **后续讲评**：本课未说明何时逐份讲评此大纲；[第9课](lesson-09.md)p19 02:14–03:51继续用夜摊场面讲配角产生，但没有说明这是点评学生上交的大纲；该课另评一份匿名少年稿，未指明作业课号。

## 课堂建议与回顾

p15 33:10–33:30建议下次遇到“气氛不对”的生活场面时，观察究竟哪些细小线索触发了这种感觉；这是持续素材观察练习，无独立上交报告。p15 00:13–00:24回顾千字八项故事；p16 02:14–02:47引用课代表改写例，不等于展示了其完整原稿或交稿过程。
