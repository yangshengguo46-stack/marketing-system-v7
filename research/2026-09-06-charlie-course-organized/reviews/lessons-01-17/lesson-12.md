# 第12课｜小蝌蚪找妈妈

原课：[p25 12.1](https://www.bilibili.com/video/BV1eE411F73t/?p=25)→[p26 12.2](https://www.bilibili.com/video/BV1eE411F73t/?p=26)→[p27 12.3](https://www.bilibili.com/video/BV1eE411F73t/?p=27)，约86分44秒。

[第11课](lesson-11.md)讲十种类型后，同学反映信息太多。老师因此再用一堂课，把《小蝌蚪找妈妈》分别向十种故事思路改写，让类型的重点落到人物、行动和事件上。这十个是课堂变体，不是一部连续电影的十段，也不是要求学生另交十篇。

## 十个课堂版本分别怎样做

| 类型与证据位置 | 老师此版的设定与发展 | 与类型重点的关系 |
|---|---|---|
| **金羊毛**｜p25 13:33–26:16 | 孤身蝌蚪因不知道自己是什么、被鱼虾蟹拒绝而出发。搭档是有温暖家庭却嫌管束的离家小龟；一起经历路途困难。蝌蚪成长后能帮助别人，不必靠找到母亲证明自己；小龟重新认识家庭。 | 找妈妈是动作，身世与自我价值是想得到的东西。路径带来成长；团队既有情感互补，也有行动上的互助。 |
| **情感**｜p26 00:24–09:10 | 把蝌蚪改成无尾、行动困难但机灵；把龟改成反应迟钝却能驮它的伙伴，以彼此救助建立需要。蝌蚪长成蛙后看到龟捕食同类，龟家人也构成威胁；它提前离开，没听到朋友为保护它与家人决裂。 | 先做出“缺一不可”，再做生命危险、误会与分离的阻隔。此设定已不同于上一版，可以另讲，也可选择并入旅程。 |
| **超级英雄**｜p26 09:10–13:31 | 蝌蚪侠能使用水的力量，但离水／变身有时限；王八精是对手。由找被害母亲入手，发现对手欲统治整个水域，责任扩为保护共同世界。 | 能力、命门、对手、使命四项；开头救人兼交代规则，弱点将来可被对手利用。 |
| **鬼屋**｜p26 13:35–17:39 | 封闭小池塘，深水区有吞食生物的大口；蝌蚪违背母亲劝告闯入，她为救它被拖走。它带着恐惧与愧疚重新进入深水寻母。 | 逃不出的空间、致命力量、自己引起问题的“原罪”共同促成行动。这里的母亲并非金羊毛版未曾认识的母亲。 |
| **侦探**｜p26 17:42–21:16 | 蝌蚪作为池塘警察，一边查凶手一边找生母，最后发现两者是同一人；母亲以生育之恩请求放过，主角选择履行警察责任。 | 探秘者、秘密、揭开答案后必须付代价的选择。课堂只做设定与结果，没有展示完整线索和推理稿。 |
| **如愿以偿**｜p26 21:57–28:15 | 蝌蚪遗憾少年时没走向大海，获得重选机会；规则是不应改变历史。误绊哪吒后龙太子得势，必须修正后果；重新回小池塘向妈妈求教，理解当下生活的价值。 | 有共情的愿望、规则、教训。老师临时撤回“哪吒被杀”的初想，改为未能收服龙太子。 |
| **麻烦家伙**｜p27 00:03–05:10 | 受保护、无忧无虑的蝌蚪，母亲突然被饭店抓走，必须冒险营救。老龟有从饭店逃出的经历，训练它通过路途与水族箱；再把居住地改为饭店后院养殖场。 | 无辜小人物、突然灾祸、生死考验。导师的经历帮助搭建路线，身体限制使其只能教，无法替主角完成任务。 |
| **变迁仪式**｜p27 05:14–13:24 | 家庭问题改为跨物种养育：蝌蚪长成蛙，发现自己与龟妈妈不同，又因身世隐瞒而冲突，离家寻找亲生母亲与同类。经历暂时的认同后，获知养母曾在灾祸中拼命救它，重新理解养育关系。 | 常见关系问题→过激／逃避应对→回归面对。共同遭灾的前情用来支撑最后理解，属于老师为此版选择的主题。 |
| **愚者成功**｜p27 13:25–21:25 | 憨蝌蚪立志当观赏鱼，进入水族馆练习表演，克服排斥后终于上场，却恰好长腿退尾，无法按旧方法游。转而用蛙的跳跃特长，意外得到孩子喜爱并领游。 | 努力适应陌生环境、表面上的融入，最终靠自己的特点获得成功。老师此版保留蝌蚪，但未再展开找妈妈情节。 |
| **被制度化**｜p27 21:29–31:39 | 水坑蝌蚪群接受猫每天来吃几只的“规矩”；点点提出向东钻出，独自坚持后有同伴加入。快成功时被拖拉机破坏并有牺牲；大雨使群体自由，点点却留在原坑陪伴牺牲的兄弟。 | 群体、个人选择、抗争与牺牲。价值从自己活命转向抗争的意义。此版也没有展开妈妈线；雨后逃出与此前工程之间的具体因果未讲清，整理不补写。 |

龟在不同版本中分别承担搭档、对手、导师、养母等功能。这些角色身份、母亲处境和结局常互不兼容；应比较改动怎样满足本版需求，而不把所有设定合并。

## 现场修改怎样影响后面

| 原想法／输入 | 原课修改 | 对后续的影响与证据 |
|---|---|---|
| 只因别人有妈妈便去找。 | 增加不知道自己是什么、被排斥的经历；将找妈妈作为理解身份的行动。 | 最后可不找到母亲，却通过行动建立自我价值。p25 14:13–17:40、20:18–24:27。 |
| 团队还没有明确搭档。 | 选家庭完整但离家的龟，不选鱼。 | 情感上互补；路途无水时龟能驮蝌蚪。p25 17:40–20:07；[19:57字幕](frames/p025-1197.jpg)可回看老师强调这是设计。 |
| 一直由龟保护蝌蚪。 | 在龟倒下时，让已长腿的蝌蚪取水或救助它。 | 把成长变为可见行动，也回收前段互助关系。p25 21:48–23:15。 |
| 蝌蚪侠离水15分钟的限制。 | 讲到变身时又提出5分钟。 | 规则用于制造可见的时间压力，但课堂未确定最终数值。p26 10:27–11:32；[11:28字幕](frames/p026-0688.jpg)确认“五分钟一到”。 |
| 蝌蚪误绊哪吒，导致哪吒被杀。 | 老师立即收回死亡，改为没能收服龙太子。 | 保留让主角纠正局面的空间。p26 25:45–26:46；[26:07字幕](frames/p026-1567.jpg)“就别把哪吒给杀了”。 |
| 老龟知道饭店路线，有能力直接带路。 | 补它逃离时受伤失明，且环境是饭店后院养殖场。 | 路线经验成为教学依据，导师无法代劳，营救责任仍落在蝌蚪身上。p27 03:31–04:45。 |
| 普通母子矛盾、离家出走。 | 改为龟养母，长大后的外形差异暴露身世疑问；再补共同灾祸和保护前情。 | 离家的具体原因、短暂同类认同和后来的理解有了相互关联的材料。p27 07:36–13:20。 |

以上是老师现场提出的方案与修正，不是已经展示过拍摄效果的定稿案例。
