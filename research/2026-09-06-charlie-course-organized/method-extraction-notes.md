# 从全课到可执行方法：整理中的约束与待验证点

本表记录全文核读已暴露的迁移问题，随后续课程补充。它是项目整理记录，不是老师的讲义，也不是已验证的 Skill。课程正文仍以逐课卡和原视频为准。

## 同一个词背后的操作不能混在一起

| 容易混同的内容 | 已找到的区别 | 对后续方法的约束 |
| --- | --- | --- |
| 八要素、五关键事件、十序列 | 第2—3课用要素发展构想；第7课安排关键事件；第8课把故事发展成序列和场面。 | 这是不同层次的写作工具。要求“故事完整”不能只检查表格八项非空；要求大纲不能只把同一梗概改成十个标题。 |
| 自选故事与指定案例作业 | 第4—5课写自己的约1500字故事，第7课尝试发展表，第8课明确改写课堂警察案例。 | 学习路线保留换题。指定案例练的是如何展开，不能宣称它验证了从零选材的能力。 |
| 警察案例的两个动机版本 | 第3课丧女动机；第8课明确沿用课代表修改后的抚恤金、妻女仍在版本。 | 每次练习指定输入版本。修改动机后，前因、行动与结尾一并检查，不把旧版片段拼进新版。 |
| 信息节拍与事件节拍 | P001 18:04–25:07反思旧教学造成“只交代信息”，改强调让信息通过事情发生。 | 后续参考旧课的结构时同时链接这段修正。正文必须有行动及反应，不能靠分析表写“这里产生共情”。 |
| 从成片拆出的数量与写作定额 | 不同拉片分出不同信息包；P063的20节拍出现在其AI写作流程语境。 | 不把某片的数量固化成所有作品的硬性字数、场数或节拍数；先明确作品形态和阶段。 |
| 概念成长与实际行为 | 第8课用同事态度、聚餐等事呈现身份变化；P068/069分析角色通过行动逐渐取得认同。 | 人物弧光不能只写“他学会负责”，需要前后选择和结果的证据。后期课堂解释的观众反应仍须读者验证。 |
| 分析格式与交付正文 | 第19课要求提交人物小传时擦除分析用的五项标签，写成连贯叙述。 | 保留工作笔记供返工，给用户的是本次要求的作品。不要把后台分析字段直接交作人物小传或故事。 |
| 影片内的A/B计划与课程AB故事 | P072《星际穿越》约06:59–07:57讲片中的两种人类延续方案；课程中的AB故事用于分析外在旅程与内在变化。 | 相同字母不是同一概念；检索后先看上下文，不能用电影计划的定义替换编剧分析工具。 |
| 故事类型与题材 | P072约32:10开始区分科幻题材与执行任务的故事机制。第11课又修正此前将《杀人回忆》称为爱情片的说法，说明只是人物关系使用了情感故事的处理方式。 | 分类用于帮助选择创作办法，保留其教学语境及后续修正；行业、道具或题材名称不直接决定故事该写什么关系和行动。 |
| 结构、看点、情感与情绪 | 第24课以四方面诊断作品，允许各有侧重；第25课强调观众情绪和角色自身情绪有区别。 | 基础练习先解决讲得完整，后续仍需发展具体吸引力、人物关系和视听感受。不能把所有质量问题化为结构表是否填齐。 |
| 人物互补与完全相反 | P077 62:24–64:05纠正把一方好人、一方极恶的机械理解，强调共同优点和处境差异；第24课也不要求按缺陷配零件。 | 从关系中的相互作用发展人物，不把“相反”做成所有属性取反。 |
| 主角主动性与作品整体取舍 | P079明确承认主角等待、对手不极端邪恶使推进困难，同时认可本片保留主题和整体气质的取舍。 | 被动大处境中可以发展具体小目标，不能用“一律主动、一律加大恶人”抹平作品差异。 |
| 成片分析与真实创作过程 | P079约51:50后五项“真实事件改编”是老师推测，未展示原始材料与剧本版本；原型纽约数月的描述也与当事人书籍简介指向巴黎多年不符，核查来源已写入P079卡。 | 不把教师从成片反推的故事当成实际导演/编剧决策记录；方法可保留为候选方向，证据类别必须随之保留。 |
| 穿越与如愿以偿 | P081 42分后用《蝴蝶效应》说明穿越可只是寻找解决办法的工具，不能见穿越就归如愿以偿。 | 保留后期案例对早期概括的限定；分类不代替阅读人物的具体目标和尝试。 |
| 信息包与新的期待 | P088开头进一步指出新信息应产生期待或好奇；单纯新增事实不一定形成推动。 | 方法不仅问有没有事件，还要问它改变了读者对当前事情的哪项期待。 |
| 有动作与单场好看 | 第34课再次处理直给、通用场面，补人物性格、变化和前后承接；小三角为辅助方法。 | 不把“改成动作”当最后一步；反向切入仍须对该人物可信，不能每场强拗反转。 |
| 儿童视角与唯一电影真相 | P087先把奇幻读作孩子的想象，16分后又允许不同理解；并区分动画与儿童内容。 | 保留解释弹性，不把教师读法冒充导演意图，也不把所有孩子写成同一种心理。 |

## 方法需要保留老师作选择的过程

“增加反转”“提升共情”“增强节奏”尚不是可执行方法。至少应让使用者看见当前问题、改动选择，以及它造成的前后影响。已核到的候选示范包括：

1. **第3课普通警察构想的逐步变化。** 八项齐全仍普通；先改变人物欲望，再补能理解的动机和行动。保留现场试探，不能把所有临时提案合成唯一答案。
2. **第8课删去过早加薪。** 原因是它会提前解除经济困境；保留荣誉变化来制造暂时上扬，后面仍有尚未解决的关系和责任问题。这里的操作不是“一律禁止主角成功”。
3. **第8课回收开场的失职。** 后来的打击来自先前放任的事情，让人物改变有因果依据；不是随意再添一个更惨的遭遇。
4. **P001催租示范。** 信息弹窗改成门口堵人、装作不在、钥匙开门与躲藏。动作产生新的问题，观众由事情理解穷困和窘迫。
5. **P064葬礼场景修改。** 用角色想做什么、为什么做不成及持续期待来发展场景；本节所举比例和集数保留为语境内比喻或案例，不转成硬规则。

以上是候选操作的来源，尚未以新作业检验迁移效果。首批将它们归入从材料写完整故事、信息成为事件、持续期待、具体一场戏、沿因果返工五种实际任务。全课交叉复核已补入第16课原因悬念、第17课批改安排变化、P092催化剂型主角等限定，避免将前段概括硬化。

## 作业和效果证据分别保存

- 原课新作业、课堂演示、旧作业讲评和长期训练建议分开归类。同一作业在多处被重述，统计的是证据条目，不虚增作业数。
- 第20课让学生先分析《加勒比海盗》，第21课实际回收；这是可对照的练习链。老师对影片的拆法不自动成为唯一正确答案。
- 第22课要求从耳闻目见的家人素材写第三视角故事。Agent没有自己的家人经历；使用用户材料可以对应原题，开发中虚构一组材料则应标记为改编练习，不能算原题如实完成。
- 课程中的学员问题稿未完整展示时，只能引用老师描述的局部问题，不补造“原始全文”。
- 完整原视频、机器全文、课程卡、来源核验、实际交稿、读者判断是不同证据。任何一项完成都不能替代其他项。

## 封装时的具体取舍

课程资料保存为普通 Markdown，便于检索、回查和在 Obsidian 阅读。操作方法以后只负责具体写作任务的输入、步骤、交付和返工，并按问题读取课程及案例。原生 App Server 执行、保存与接续；无须增加知识库服务或第二运行时。

初次试用的方法作为候选材料显式给 Lead 使用，保留失败与修改记录。只有实际练习说明它能帮助完成任务，才决定是否做成正式可发现的 Skill。不能用“已生成 SKILL.md”代替能用、好用的验证。
