## 整理原则

先按老师课程顺序建立课程页，再在页内注明他明确引用的前课材料及后续用途。每页写清讲了什么、怎样示范、案例用来说明什么、在哪里明确要求练习或交作业、老师是否展示讲评。不把电影分析误写成作者真实创作过程，不虚构原课没有的改稿前后版。

作业分三种原课事实：明确布置的作业、课堂练习建议、回顾前次作业。我们的练习安排如果以后需要添加，单独标为自拟，不能混入老师作业。只出现“作业”一词未必是在布置；没搜到关键词也不能宣称没有作业。关键命令、否定和数量要求回到原视频核查。

机器转录全文阅读仍有同音错字和案例漏识别风险；需要画面配合的拉片、板书或无声片段应明确指出。保留疑点，不靠常识填全。

## 放在哪里、怎么使用

以普通 Markdown 课程资料包为主，兼容 Obsidian。完整课程内容及证据保存在资料文件中；小 Skill 只适合以后承载已经练习过的具体操作步骤及取材指引。暂不创建向量数据库、安装社区插件或把全课塞进模型上下文。

Obsidian 的取舍见 [本轮官方资料核查](obsidian-decision.md)。它承担人的课程阅读、笔记互链和作业记录；现有原生 App Server 继续承担模型和工具执行。资料结构先服务课程的清楚完整，再服务搜索。
