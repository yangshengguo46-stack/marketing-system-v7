# 首批方法的独立交叉复核

以下是本轮并行核读者对 Lead 整理的方法文字提出的具体问题，记录实际采纳结果。它是来源忠实度与适用边界检查，不是新故事效果评测。

| 文件/问题 | 复核依据 | 已做修改 |
| --- | --- | --- |
| 沿因果返工：“每次困难必须改变办法”太硬 | 后半课核读者指出同一目标、同一办法也可承受递增代价；第29课是有针对性的攻击 | 改为改变处境、选项、代价或推进对抗；不用每次换招。 |
| 返工缺少原课真实作业的反馈链 | 第28课布置旅程→29课收到作业后讲缺乏攻击性→要求同题改 | 加入选择攻击来源作用于实际人物、关系或目标的例子；保留不能全组合塞入的限定。 |
| 信息变动作后仍可能很普通 | 第34课已针对直给、通用、缺变化的场面补课 | 加入人物性格、场内变化、前后承接；另整理具体单场方法。 |
| 入口能找完整性问题，难找“讲清但无聊” | 第30课的持续期待及具体钓鱼示范 | 增加“让读者想继续看”入口和方法；不是增加泛用刺激开场。 |
| 持续期待被限定为将来行动的结果 | 早课核读者以第16课36:33–38:57省略通话/先给结果举例 | 补入追问原因和信息是否可信，允许原因悬念。 |
| 新问题必须由前一动作造成，排除了合理新阶段 | 第13课允许长篇反复激励；仍需人物和关系连续 | 改为检查新问题怎样接回目标、人物或处境，优先用旧事后果，而不设唯一因果来源。 |
| 原课模式也可能被入口强拉去写正文 | 第1课幻想、第7课发展表、第17课自查色块不同交付 | 明确按原题交付；观看、标记、大纲不能一律扩成故事正文。 |
| 每个人都必须明显成长的潜在误读 | P092接受催化剂型主角，激励与弧线不明显 | 完整故事方法中保留例外，不为填结构强造人物反转。 |

后半课核读者复核最初三个方法及入口；早课核读者在读完1–17后复核持续期待、具体单场与入口。新单场方法保留“需要时”“非每场”等条件，未发现明显需要阻止试用的硬化。上述判断来自模型协作，原片示范也大多是教师对成片的解释，不能称作者实际创作过程或真人专家评审。

下一步使用一份完整原课式作业检验取材、成稿、具体反馈与返工，所有候选方法仍不安装为自动触发 Skill。

学习路线另经转录/补充核读者交叉检查：第18–19课不能被写成新增开场/提案/小传三选一作业；P084商业改编也没有必须保留原片静态和价值落点的约束。两处已改。Lead汇编时一度将P089片名误写为《触不可及》，已按原索引和全文卡纠正为《金氏漂流记》，未留在交付路线中。
