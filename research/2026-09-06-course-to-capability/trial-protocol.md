# 第一轮材料到能力的实际试用

在看结果之前确定：同一模型 glm-5-2-260617，经现有 codex-app-server 原生循环，每个条件使用新会话；两道已写定的开发题，各跑一次。

三种条件：只给题目；题目加本轮核对过的课程内容笔记；题目加从同一份内容整理的候选使用方法。第二组是课程内容概述，**不是完整原课或逐字稿**。方法版不能额外得到题目答案、定制情节或编辑反馈。每组都用相同的研究、方向、正文保存要求。保留请求、实际工具调用、原生工作、正文和 token 用量；不使用模拟响应。

这六次只是用于找问题的小试验，没有重复采样，无法消除模型随机性，不能证明提升幅度或一般能力。Lead 将指向实际文字给出编辑意见；Lead 参与方法整理，因此这不是盲评、真人读者反馈或独立专家评估。用户反馈尚缺。

先看故事是否成立：人物此刻要什么；行动是否改变局面；新动作是否承接前因；结果是否回应前面的问题。再单独看读者是否有继续读的理由、人物是否可信、收尾是否靠解释。允许原始版更好、方法版变僵、全部不够好。无关的“结构齐全”“用了课程术语”和更长的说明不计作改善。

保留边界：生活片段不一定需要强冲突或极端第二动作；本轮试题明确要求完整故事，所以采用故事发展方法。未来不能把它扩成所有 IP 表达都必须剧情化的规则。

## 后续执行补记

用户在试跑中明确授权并行子 agent 后，另加入一位不知道条件映射的独立模型编辑。六份正文按随机标签复制，ready.json 记录哈希；评阅完成后再由主 Lead 对回条件。故现在包含一次匿名模型评阅，仍不是真人读者反馈，也不具备统计充分性。原先两次越界试跑作废并保留；全部六个正式条件统一采用更明确的原生工具参数说明重新开会话。六次正文不作事后修订。另有一次使用具体编辑意见的返工，单独标记，不能作为候选方法独立增益。
