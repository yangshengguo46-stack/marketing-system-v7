# 第一份故事-工作笔记

本文件只记构思与方法依据，不是故事正文。

## 初稿（v1）阶段

### 任务与规格
- 第4—5课原课规格：五个入口选一个，写约1000—2000字、目标1500字的完整线性故事，包含八项关系，按顺序写到结果。第7课将此稿称为梗概。
- 虚构起点：街边修鞋铺今天必须提前关门；店主答应看女儿第一次登台；离出发剩十分钟，顾客坚持今天拿鞋。
- 限制：不借突然重病、死亡、极端恶人或长篇煽情独白增加分量；不写营销卖点、拍摄方案或视频；不复述课程警察案例，不看旧试写稿。

### 初稿构思入口
第4课第四种入口：悬念（时间锁）。依据 p10 09:32–15:44。

### 初稿八项关系（自查用）
- 身份：老周，街边修鞋匠，独自带七岁女儿小满。
- 欲望：赶上女儿第一次登台；同时不愿交出没收尾的鞋。
- 动作：用最快但认真的方式把右帮收尾走线、交鞋，再锁门赶去。
- 核心问题：十分钟内能否既守住手艺、对得起顾客又赶上登台。
- 障碍：顾客今天要、鞋还差收尾、时间紧、自身手艺标准。
- 结果：鞋给了顾客；他迟到但赶到。
- 正价值：守约与在场、手艺诚实；负价值：无法完美，以迟到为代价。
- 主题方向：在被撕成两半的时间里如何选择不彻底辜负哪一边。

- 第34课：小三角创作法，43:28–44:28 布置两部分作业

### 独立评阅与返工要求指出的三处问题

**问题1：时间与代价。**
v1 开头说四点登台、三点五十走且车程十二分钟，却说"不晚"；3:50+12=4:02，若小满4:00登台则"不晚"在算术上不成立。后面才补"节目排在第四个、前面三个约十五分钟"，使读者以为此前紧迫是靠信息晚给制造的。评阅判断准确。

v2 修正：从开头统一时程——整场4:00开始，小满节目《春芽》排第四，前面三个约十五分钟，小满约4:15上场。老周从开头就知道这个安排（不是后补信息）。最迟4:00出发，4:12到。顾客3:50到，离必须出发还剩十分钟（对应题目）。修鞋至少5分钟，做完3:55–3:58，锁门1分钟，4:00之前能走。实际3:59出发。他本来绰绰有余，顾客的到来吃掉了余量——紧张是真实的，不靠信息晚给制造。

v1 旧研究称"迟到必然是代价"——此说法已失效。v2 中老周并未迟到，但困难是真实的（余量被压到极限，一分钟的容错）。按返工要求"允许赶上，不要求一定错过；但不能称付出了并未发生的代价"。

**问题2：物件连续性。**
v1 顾客进门"手里拎着一双黑色浅口皮鞋"，后面鞋又在店里等店主取与缝。鞋既然是送来修的，应该在店里。

v2 修正：顾客进门时未拿鞋，老周转身从架子上取下纸袋拆开检查。鞋始终在店里。删除"手里拎着一双"。

**问题3：人物理由。**
v1 老周明知至少五分钟却说两分钟，解释为"不想让她站着等一个不准的数"——行为与解释互相否定。

v2 修正：老周报两分钟是因为他先相信自己能砍步骤加速（砍掉烫线头、不走热风压实）。这是一个手艺人在压力下的自我算计，不是矛盾。随后在干活时一步步发现砍不掉——第二针偏了不得不拆、烫线头没省——他的心理从"能快"变成"算还差多少"。这个变化有可信过程，不靠一句作者解释自圆其说。

### 第34课单场练习
选修鞋场面应用小三角：
- 诉求：表现老周在手艺责任与父亲承诺之间被撕开。
- 直写：写他着急看钟、想扔下鞋跑。
- 反向一侧：先写他比平时更慢、更仔细——拆掉走歪的第二针、检查已粘牢的左跟、烫平本想省掉的线头。
- 回到诉求：顾客说出见姐姐的理由后，"慢"有了含义——他在认真对待别人同样重要的时刻；但这认真正是让他差点赶不上的原因。
- 单场练习见第一份故事-第34课单场练习.md。将改好的场面接回完整 v2。

### v2 与 v1 的主要文本差异
1. 开头时程全部统一（整场4:00、小满第四个、最迟4:00出发），删除"不晚"的错误判断，改为"他本来绰绰有余"。
2. 顾客进门不拎鞋，老周从架子取鞋袋。
3. "两分钟"的动机改为自我算计（想砍步骤），在干活中发现砍不掉。
4. 修鞋场面用小三角改写：先慢（拆第二针、检查左跟、没省烫线头），再由顾客理由回到诉求。
5. 出发时间改为3:59（非4:01），他并未迟到，余量被压到一分钟。
6. 删除"他知道自己会迟到"，改为"他还有一分钟余量"和"算了一下午，该做的做了，剩下的交给路"。
7. 结尾保持安静气质不变。

### 沿因果返工的检查
- 动机改变（报两分钟→自我算计）影响后续：他在干活中发现砍不掉，手反而稳了——这接续到"不是不急，是急也没用"，逻辑一致。
- 物件修正（鞋在架子）不影响后续：取鞋→拆开→发现没收尾→修鞋，链条通顺。
- 时程修正（4:00出发而非4:01）影响结尾：他不再迟到，但困难真实，结尾不需改。
- 顾客理由不变，与v1一致。

### 仍不确定/留待判断
- v2 让老周赶上（有1分钟余量），是否显得过于顺利——但这是诚实的时间计算结果，不为紧张制造虚假代价。
- "两分钟"自我算计是否足够可信，或需要更多行为证据。
- 顾客"十年没见的姐姐"是否仍显偏巧——v2未改此设定，保留。
- 第34课小三角的"反向减速"是否足够贴合老周这个人，而非仅为三角而三角。
- 未做读者效果验证，仍属模型自评。

### v2复核指出的一项必须修 + 编辑建议

**必须修：时间推算。**
v2正文："3:52……他最快也要五分钟。也就是说，做完刚好卡在四点，没有余量。"
错误：3:52 + 5 = 3:57，不是4:00。正文没有给出额外三分钟的工作或等待，却把工时算满到八分钟，以此构成"只有两分钟入场"的紧张。

v3修正：删除"也就是说，做完刚好卡在四点，没有余量。如果锁门推车再花一分钟，他就得在四点零一分出门，到少年宫四点十三分，离小满上场还有两分钟"整段算账。改为"走线、收尾、烫线头，他最快也要五分钟。如果不出岔子，还来得及。但五分钟是最顺的情况。"——3:52+5=3:57，离最迟出发（4:00）还有3分钟余量，如果不出岔子够用。实际因返工多花约2分钟，3:59完工，4:00出发，4:12到，4:15小满上场，还有3分钟找座位。紧张来自不确定性，不是假算术。

**编辑建议（已处理）：删掉先讲分析再用动作重复的解释。**
- 删："这是一个手艺人在压力下的算计：先相信能快，再在干活时一步步发现砍不掉。"——叙述者预告行动将证明什么，随后行动又演一遍，重复。改为"他知道不止两分钟。但他想先做着——也许能省几步。"
- 删："他明白了'场合'是什么——这双鞋不只是今晚穿的，是去见一个十年没见的人时穿的。"——重述读者刚从顾客话中接收的信息。改为不解释，直接写老周没加快没放慢、没省烫线头。
- 删："这不是给顾客看，是他自己要的。"——替动作定性，让动作自己说话。
- 删："他不再算自己能多快，开始算还差多少。手反而稳了——不是不急，是急也没用，这件事只有做完才算完。"→简化为"他不想了，接着走。第三针、第四针，手稳了"——保留身体变化，删解释性旁白。

**编辑建议（已处理）：删掉与十分钟场面不符的夸张。**
- 删："他不想再算了——算了一下午，该做的做了，剩下的交给路。"——场面约十分钟，"一下午"是夸张。改为"四点整。"——只留出发时刻。

### 数字与计算留在笔记，正文只保留读者必要信息
v2开头有"也就是说，他最迟四点出发，骑车十二分钟，到少年宫四点十二分，还有时间停车、进场、坐到第三排"——算术链。v3改为"从铺子骑电动车到少年宫，十二分钟。他最迟四点得出门。"——只留读者需要知道的约束（演出时间、女儿排序、骑程、出发截止），不替读者算账。
v2有"这些事他每天都做，今天做完只花了一分钟"——精确计时属于算术。v3改为"今天做得快"。

### v3时程核算（用python3核对）
```
整场4:00开始，小满第四个，前面三个约15分钟 → 小满约4:15上场
骑车12分钟 → 最迟约4:03出发可到达4:15（但需留找座时间，目标4:00出发）
看钟3:52 + 最低工时5分钟 → 最早完工3:57，离4:00出发还有3分钟
实际工时约7分钟（返工多2分钟）→ 实际完工3:59
交鞋+锁门约1分钟 → 出发4:00
骑车12分钟 → 到达4:12
小满约4:15上场 → 到达后还有3分钟找座位
第三节目仍在演（4:10-4:15区间），老周坐到第三排
```
紧张来自：最低工时5分钟+可能出岔子，实际出了岔子（第二针返工），余量从3分钟压到极限。但他确实赶上了，不制造虚假代价。
