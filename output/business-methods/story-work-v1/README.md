# 从完整课程到实际创作

这是一组研发中的候选做法，服务于产品“一站式完成优质、可传播的作品并获得影响力”的目标。它只覆盖故事创作与创作取舍，不代表研究、视听制作、发布或营销效果已经完成。

## 按当前工作使用

- **遇到从材料成篇、事件展开或整体返工的具体难题：** 按需读取[完成与返工故事](完成与返工故事.md)，把题目、实际材料和明确限制一起交给执行模型；要求直接完成正文，构思笔记另存。缺少事实时区分能自行取舍的创作选择和必须取材的事实，不让客户先学课、填方法表。
- **要按证据决定采用、返工或补材料：** 可显式读取[依据正文作创作取舍](依据正文作创作取舍.md)，先给任务和完整正文，先留下实际理解，再看作者说明。反馈必须落到正文及影响，合理写法可以不改。
- **某个方法不理解或遇到例外：** 按方法内链接回到[完整课件](../../course-learning/charlie-20260906/全课课件/README.md)及连续讲义。课堂过程、教师假设和实际验证结论各自保留，不把教师意见当成适用于每篇作品的公式。

当前通过显式任务加载普通 Markdown。尚不安装自动触发 Skill，不改底座；原生 `marketing_work` 仍负责研究、方向和完整稿的保存、重新打开及返工状态。只有文件工作区的独立对照会保存文件，不冒称原生工具入库。

## 首轮结果与使用边界

两道新题的首稿比较中，两位匿名模型编辑均小幅偏好不带课程的GPT-6；六份明示问题/合理例外诊断中，有无Lead方法均命中预设命题。当前**没有显示这些通用步骤对强模型的额外质量收益**，不作为每次写作的默认必经流程。原生GLM模型的实际场面暴露了算术、反应重复及作者说明超出正文的问题，另行执行有依据的返工；这只能检验该次修复，不抵消新题比较结果。

[一次完整返工的做法与边界](一次完整返工的做法与边界.md)保留了实际前后稿、改法、代价，以及原生执行的回读与保存缺口。这份补充写于试用后，没有参与冻结v1的新题比较。

## 当前证据入口

[首轮执行与判断试用](../../../research/2026-09-09-story-method-lead-pilot/README.md)保存冻结方法、共同新题、首稿、独立模型读稿、诊断题与返工证据。课程来源核读与新题执行相互分开；小样偏好不能证明稳定优势，模型意见也不能代替目标读者与编导的反馈。

对强模型是否有增益，以相同条件下的实际结果为准。保留方法是为了完成任务，不为维护课程形式；已经能直接做好的部分，不增加必经步骤。未来模型增强时应重测并删减无增益做法，不以“除非 AGI”作为竞争力保证。
