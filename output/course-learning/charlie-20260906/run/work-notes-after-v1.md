# 第一份故事-工作笔记

本文件只记构思与方法依据，不是故事正文。正文见同目录「第一份故事-v1.md」。

## 任务与规格
- 第4—5课原课规格：五个入口选一个，写约1000—2000字、目标1500字的完整线性故事，包含八项关系，按顺序写到结果。第7课将此稿称为梗概。
- 虚构起点：街边修鞋铺今天必须提前关门；店主答应看女儿第一次登台；离出发剩十分钟，顾客坚持今天拿鞋。
- 限制：不借突然重病、死亡、极端恶人或长篇煽情独白增加分量；不写营销卖点、拍摄方案或视频；不复述课程警察案例，不看旧试写稿。

## 选择的构思入口
第4课第四种入口：悬念（时间锁）。依据 p10 09:32–15:44——危机、时间锁、秘密或疑问让人等待尚未解决的结果。题目本身给出倒计时（十分钟、必须出发、登台时刻），持续等待的是"他能否既对得起顾客又赶上女儿"。时间锁向外生发人物与行动。
未选激励事件入口：顾客到访虽是干扰，但故事发动机是时间压力与店主自身两难，时间锁更贴。

## 八项关系（自查用，未写入正文）
- 身份：老周，街边修鞋匠，手艺讲究，独自带七岁女儿小满。
- 欲望：赶上女儿第一次登台；同时不愿交出没收尾的鞋。
- 动作：用最快但认真的方式把右帮收尾走线、交鞋，再锁门赶去。
- 核心问题：十分钟内能否既守住手艺、对得起顾客又赶上登台——答案是不能两全，故选择"对得起两边的迟到"。
- 障碍：顾客今天要、鞋还差收尾、时间紧、自身手艺标准。
- 结果：鞋给了顾客；他迟到但赶到，坐上第三排留座，看见女儿登台。
- 正价值：守约与在场、手艺诚实；负价值：无法完美，以迟到为代价。
- 主题方向：在被撕成两半的时间里如何选择不彻底辜负哪一边，而非"迟到好不好"。

## 关键虚构与依据
- 老周、小满、修鞋铺、顾客（灰外套女人）均为虚构。
- 顾客理由（与十年未见的姐姐今晚见面、明早走）合理虚构，使店主让步有可信代价，对应用"只共情主角不够，也要理解配角处境"（第5课 p12 05:54–07:04）；用平常性对冲"太巧"风险，未写重病死亡。
- 鞋"右帮还差两厘米收尾"是制造两难的具体障碍，避免顾客只是无理取闹。
- 老周不换衣服、有胶渍：刻意保留一个真实缺憾，不完美化主角。

## 沿用的课程办法（来源）
- 方法/从材料写完整故事：先说清谁想要什么、对谁行动、必须解决什么、谁阻挡、最后如何、得失如何；让人物先做符合处境的事再遇反应；下一步由结果引出；结尾回应此前持续等待的问题。
- 第3课借用的是选择过程（先发现平淡、提出可能性、检查可信度与后续影响），不照搬"想殉职"动机，不硬加怪异标签。
- 第5课：人物结局不必圆满；只共情主角不够。
- 检查办法：让未读笔记者只看正文复述"谁要什么、先做什么、为什么改、最后怎样"。

## 自查（候选问题，非吸引力验证）
- 顾客理由与女儿登台形成两条"被时间逼的人"的并行，已克制点题，未强行并列抒情。
- 结尾落在"肩膀松下来"的画面，未写内心总结，交给读者。
- 仍不确定：顾客"十年没见的姐姐今夜路过"是否仍显巧；老周迟到却仍赶上是否过于温和——留待具体反馈再返工，不自行连跑多版挑最好。
