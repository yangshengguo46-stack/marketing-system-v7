# 沿因果返工

适用于已经有完整故事或大纲，需要处理动机不足、进展重复、成长过早或结尾不成立等问题。输入应包括当前稿件、此次目标和反馈；局部稿件只能支撑局部判断。

## 将反馈落到读者实际遇到的位置

先找到具体段落和读者感受到的问题。“不好看”还不足以决定改法；可以继续定位：读者为什么还不知道主角要什么，哪里已经提前解决主要困难，哪几次尝试只是换地点重复，结尾哪项选择缺少前面依据。

第24课提供结构、看点、情感、情绪四方面的观察角度。用它们帮助辨别问题，不要求四项平均加料。第25课的情绪分析说的是观众怎样感受，不能用“人物愤怒”证明“观众已经愤怒”。

## 找到问题与前后的关系，再选改动

回读这一段之前的人物处境、已做的事和后面还要处理的问题。提出能处理眼前问题的改法，并说清会影响哪里。下列是课程中有上下文的例子，供选择时对照：

| 具体问题 | 教师改法或建议 | 为什么这样改；还要检查什么 |
| --- | --- | --- |
| 想给妻女留下钱的警察过早得到加薪 | 第8课删去加薪，保留荣誉和他人态度的上扬 | 钱的问题若已解决，后面的行动动机减弱；保留暂时成功，不意味着主角必须一直失败。 |
| 后段危机像又来了一件倒霉事 | 第8课让前面放任、失职的事情产生后果 | 困难来自人物以前的选择；开场必须确实存在相应行动，不能在后段临时声称曾经发生。 |
| 追查故事前面绕远，后面又都是追人 | P074《保你平安》建议调整与主线联系弱的阻碍，将后段行动做出变化 | 让困难改变处境、可选办法、代价或推进对抗；不必每次换招，也不是不停增加新的敌人或地点。 |
| 人物似乎已经获得全部认可，后面仍拖着主线 | 同一拉片讨论女儿认可与成长的时机 | 先分清哪一条问题已经解决，哪条仍悬着，再调整兑现位置；延后认可须保留关系变化的过程。 |
| 结尾恢复了前面已经放弃的旧办法 | P075《男妇女主任》质疑结尾再次靠欺骗解围，考虑前移该段 | 结尾行动是否抵消此前由假到真的转变；必须连同前面成功和关系变化检查。 |
| 公路故事只是逐站发生事情，对主角影响不够 | 第29课针对收到的第28课作业，选择攻击来源作用于人物缺陷、技能、关系或行动目标 | 写回实际事件及后果；35:36–35:52提醒不要把所有组合全塞进同一稿。 |
| 内心成长只在结尾被宣布，中间没有可信过程 | 第15课先单列成长的变化点，再寻找可承载它的已有事件；确实没有载体时才补事 | 新增行动仍须接回外部任务，不能平行写两套无关剧情；人物改变了哪项判断，要能在其选择中看到。 |

这些是老师的案例判断和修改建议。原片未按建议重拍，不能称为修改效果已被验证。

## 改同一份稿子，并兑现受影响的地方

选择与当前反馈最相关的改动，写出修改后的正文。动机改变会影响选择和结尾；删去一个成功情节可能影响人物资源、身份和旁人的态度；提前或延后危机可能影响读者知情范围。逐处检查这些实际依赖，保留仍成立的部分。

工作文件保留旧稿及版本关系。若使用本项目原生作业链，上游改变后下游旧稿的“待复核”状态表示需要检查这些影响，并不等于下游自动失效或已经重写完毕。

## 交付与复核

交付修改后的完整稿或用户指定的完整段落，附简短改动说明：原问题在哪里，改了什么，前后哪些地方随之调整。读者应能只看作品理解故事，不需要先看分析表。

复核原问题有没有改善，以及新稿有没有新矛盾。可以请另一个 Agent 独立读稿指出断点，但其判断仍是模型意见。保留争议和仍未解决的地方；真实读者是否更想继续看，需要另外获得反馈。
