# 从材料到完整故事，再到具体剧本

这条路线把全课的学习顺序和真正动手的位置连起来。[全套目录](全套目录.md)保留每个原视频，[原课作业](原课作业.md)保留逐条要求、时间和讲评证据。这里不另外发明“一课一作业”，也不把不同题材强接成同一个故事连续写到底。

先结合[课程核心方法论](课程核心方法论.md)理解这条顺序：人物的处境与行动产生事件，事件发展又检验人物的判断、关系和信念，具体写法帮助观众经历这个过程。本页是课序与作业的路线，不承担整篇作品中心表达已经成立的判断。

## 各阶段在解决什么

| 原课程 | 要学会处理的事情 | 进入下一阶段时带着什么 |
| --- | --- | --- |
| [1](课程/第01课.md)—[3](课程/第03课.md) | 从观察、共情、愿望与恐惧取得材料；理解人物为什么行动；区分要素齐全和有吸引力 | 可追溯素材，或明确标为虚构的开发设定；尚不能用八项表格宣称故事写完。 |
| [4](课程/第04课.md)—[5](课程/第05课.md) | 从五种入口中选一个，写自己的完整线性故事 | 约1000—2000字、目标1500字的故事稿；第7课称为梗概。 |
| [6](课程/第06课.md)—[8](课程/第08课.md) | 了解格式，将概述发展成具体事件，再展开十序列 | 自己梗概的发展表；第8课另换指定警察案例做大纲。序列可有多场戏。 |
| [9](课程/第09课.md)—[12](课程/第12课.md) | 配角、搭档、组合主角与类型怎样改变事情；看同一素材的不同构想 | 角色的实际作用及故事方向选择。十种类型和十版示范不等于必须交十篇。 |
| [13](课程/第13课.md) | 整剧人物、关系发展怎样切进单集，再由事件共同承载 | 若写连续剧，保留整剧与单集的承接；电影/短故事不用强改成多集表。 |
| [14](课程/第14课.md)—[15](课程/第15课.md) | 单场动作、对白与进出；十五节拍帮助补具体事情；A事件和B变化怎样相连 | 第14课先反写两段成片；第15课回到发展事件与内心变化，不能把它们写成两套无关剧情。 |
| [16](课程/第16课.md)—[17](课程/第17课.md) | 悬念、反转及新手常见问题 | 带完整稿检查信息如何供给、写法是否服务当前故事；第17课给对手、入场、情绪色块等自查建议，没有新题重交。 |
| [18](课程/第18课.md)—[19](课程/第19课.md) | 开场选择、顺序取舍、提案和人物小传 | 第18课是观摩建议；第19课讲项目向合作方展示时的提案和小传，并未另布置三选一作业。 |
| [20](课程/第20课.md)—[21](课程/第21课.md) | 从成片学习结构、主角、AB故事及转换；比较自己的拉片和老师的解释 | 《加勒比海盗》先自行分析，再看第21课的回收；老师的拆法不是唯一答案。 |
| [22](课程/第22课.md)—[24](课程/第24课.md) | 高潮、喜剧以及结构/看点/情感/情绪；按关系与方向重新构故事 | 第22课写家人故事；第24课换《战国》重写梗概。不同题目分别保留。 |
| [25](课程/第25课.md)—[27](课程/第27课.md) | 观众情绪、英雄/反英雄变化与叙事视角 | 回查原稿及观看指定作品；角色有某种情绪，不证明观众获得同样感受。 |
| [28](课程/第28课.md)—[29](课程/第29课.md) | 命题旅程的行动、伙伴、中点与偿还；针对真实收稿问题增加攻击性 | 一份旅程作业及同题修改稿。这是全课最明确的一条布置→收到作业→共性反馈→返工链。 |
| [30](课程/第30课.md)—[32](课程/第32课.md) | 持续注意、题材与具体期待、穿越和游戏规则 | 让人知道正在等什么；第32课另做游戏题材方案，未规定必须交整部剧本。 |
| [33](课程/第33课.md)—[34](课程/第34课.md) | 结合具体问题补充；把已经有动作的一场戏写出人物、变化和承接 | 第34课三角结构/关键词加具体一场戏。另付费训练营的整剧本作业不是本公开课材料。 |

## 补充专题怎么接进来

补充视频不是第35课起的顺序续课。先完成对应基础，再按实际问题回读：

| 需要发展什么 | 补充材料与实际练习 |
| --- | --- |
| 信息怎样变成事情 | [P001](补充/P001.md)对旧“信息节拍”教学的修正；[P064](补充/P064.md)葬礼场景如何从意图发展行动和期待。 |
| 搭档与相互改变 | [P068](补充/P068.md)/[P069](补充/P069.md)《玩具总动员》，[P077](补充/P077.md)《闻香识女人》；互补不等于所有属性相反。 |
| 喜剧怎么具体起作用 | [P071](补充/P071.md)把其他喜剧中的实例填入14种方法；数量是所讲方法，不是每项必须交多少例子。 |
| 知情差、结尾与对抗 | [P073](补充/P073.md)《无间道》：回看知情差；自拟结局为思考/可写；另明确把现有第四幕**增加十分钟**。 |
| 选什么人生片段 | [P080](补充/P080.md)在自家亲戚中找值得写传记的人及人生阶段；先选材料，不要求立刻整剧本。 |
| 期待与处境如何破灭 | [P082](补充/P082.md)列朴素希望、设计破灭，把个人环境放入大环境；不是每个人固定凑七八条苦难。 |
| 主角任务如何重新集中 | [P083](补充/P083.md)按双司机带儿童列车的改法写约1500字梗概。配套失误、家庭与行动须一并调整。 |
| 按不同创作目标改已有素材 | [P084](补充/P084.md)愿意者用现有人物元素重排商业故事；另行观察原片静态叙事和余韵，不预设商业版更好，也不限制改版必须保留原价值落点。 |
| 封闭环境的群像 | [P085](补充/P085.md)设计本土背景鬼屋里的十个人；关系和秘密要能在压力下改变行为，本题未要求整部剧本。 |
| 儿童视角与动画的区别 | [P087](补充/P087.md)从具体孩子的担心、期待和判断来写；推荐再看《绿野仙踪》《菊次郎的夏天》。动画不是年龄标签。 |
| 重复动作的频率与节奏 | [P088](补充/P088.md)数《摔跤吧爸爸》中摔跤的次数，再判断是否过多、如何影响节奏；不是把次数抄成创作定额。 |
| 双主角、成长与信息选择 | [P089](补充/P089.md)《金氏漂流记》课后剖析两个角色；本土化与女方线优化可脑中推演，爱情八步为自行打点练习。[P090](补充/P090.md)—[P092](补充/P092.md)《肖申克的救赎》允许不同颗粒度与催化剂型主角，不另布置完整剧本。 |

## 本项目怎样检验方法

课程整理与写作能力分开记录。[Agent入口](Agent入口.md)按当前问题选择小方法和相关课堂示范；先完成一份完整原课式作业，再接受具体反馈、修改同一稿，检查前后影响。需要单场练习时，再按第34课真实规格提交两部分并接回原稿。

我们保留原题、开发设定、初稿、编辑意见、修改稿及未解决的问题。内部模型编辑不是老师批改，也不是真实观众数据。第一份作业能运行，只说明这条取材和写作路径实际可用，不能说全课能力已掌握。
