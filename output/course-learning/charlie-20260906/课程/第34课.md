# 第34课｜查理小三角创作法

原课范围：[P60](https://www.bilibili.com/video/BV1eE411F73t/?p=60)，47:24。已完整逐段读过[机器全文](../转录/P060.md)，未逐句听校。关键作业字幕已抽帧核实；源文件、CID、SHA256见同名JSON。

## 实际分节与目标

| 源时间 | 实际教学内容 |
|---|---|
| 00:10–03:08 | 从近期收到的作业共性问题切入：大结构完整，但单个事件/单场/信息包仍像流水账。不能只用“戏感差”笼统解释，要给具体情节设计办法。 |
| 03:11–05:10 | “表现妈妈爱主角”示例：让妈妈口述爱与付出最直接；换成做饭/织毛衣也未必精彩。已知道这一场的创作诉求，不等于会选具体事件。 |
| 05:11–08:29 | 原有办法①核心对抗：从人物目标、对手、困境找入口，至少具备三者之一，形成可视化事件。必须保留的话可放在做事中说，不是所有台词都禁止。 |
| 08:30–09:11 | ②单场有转折/变化；不是一根直线。老师允许反转，但并未把所有变化缩成结尾惊天逆转。 |
| 09:12–10:17 | ③线索延续：本场接前场，变化又影响后场；观众可预见后面会用到的东西，会愿意继续看。 |
| 10:18–15:17 | ④贴合人设：写再长的设定，若落到正文仍是可套给任何人的吵架、织毛衣，就浪费了人设。用“夫妻关系不好”比较抱怨、互打与按具体人物选事件。 |
| 15:18–16:37 | 说明以上此前课程/直播已讲，但很多人仍不会选情节；新增第五种辅助方法，将旧“正戏反写”模型化，命名“查理小三角”。 |
| 16:38–22:16 | 可怜小孩示例：直写穷、哭、破鞋、买不起冰淇淋，改为先写懂事、独立坚强、给爸爸做便当，再由忍不住想尝别人丢的冰淇淋壳显露真实渴望，回到可怜诉求；转回来点到为止。 |
| 22:18–23:48 | 表现穷：不只写抠门，先写装大方，再被拆穿/撑不住。举《夏洛特烦恼》摆阔作参照。 |
| 23:49–27:48 | 关系差可先写没有情感的例行亲密，再由插曲争吵暴露裂缝；关系好也可从一次争吵的妥善化解回到甜蜜。第五法与前四项匹配，不替代它们。 |
| 27:49–33:03 | 播《耳朵大有福》小卖店买东西片段；教师设定读法是经济窘迫者先装阔。 |

| 37:33–42:29 | 引介并播《当幸福来敲门》父子无家可归片段：先把躲藏变作想象冒险游戏，以欢乐表层反衬绝境。 |
| 42:30–43:25 | 按小三角复核：无处住的困境，假欢乐维持不住，敲门把父亲拉回走投无路。 |

## 前课依赖与当堂限制

- 05:35、08:30、15:18反复回指以前讲过的核心对抗、单场转折、线索与人设方法；没有在本P指定全部原课号，勿擅自填齐。
- 15:47–16:37及27:10–27:48是在把此前“正戏反写”变得可操作；不是声称发明与前四条无关的新结构。小三角作用于单场/单个事件/信息包，不要求把整部长片改成三幕的三个角。
- “至少三者之一”（07:05–07:10）指目标、对手、困境的入口，不是每场必须塞三个对手，也不是要另交三套方案。
- 21:57–22:06明确回到原诉求后点到为止，不要恋战；不能借绕行无限拖长。
- “假独立/假坚强”是示例中外在表现不能遮住真实需求的说法，不该改为所有坚强儿童都在伪装的心理断言。关系好的示例也表明绕行不必总靠揭穿骗子，而可借行动化解冲突。

## 老师明确作业

**创造一个小三角情节，分两部分交。** P60 43:28–44:17；44:18–44:28说明适用于全体自学班；47:02–47:14说明直播选典型作业批改。

1. 先画/写三角结构、三角公式和关键词：想表现什么，原本会怎样直写，去反向的一侧怎样绕一下，再如何回到原诉求。
2. 据这个公式写出具体的一场戏/一段剧情。

必要机器原文：

> 43:53–44:07：“先写一个三角公式，然后根据这个公式给我写一段剧情……分两部分啊……再把具体的这场戏给我写出来。”
