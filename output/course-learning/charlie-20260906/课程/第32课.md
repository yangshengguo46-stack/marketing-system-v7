# 第32课｜跟《鱿鱼游戏》学写强设定

原课范围：[P58](https://www.bilibili.com/video/BV1eE411F73t/?p=58)，81:51。完整逐段读过 [机器全文](../转录/P058.md)，未逐句听校。原文件、CID、SHA256见同名JSON；以下是课程整理，行业及作品史实口述没有额外核验。

## 实际分节与教学目标

| 源时间 | 实际内容与目标 |
|---|---|
| 00:12–06:32 | 从录课当时《鱿鱼游戏》热度与文化输出谈起，简介负债者进入封闭游戏、胜者获奖败者死亡；明确本课不做完整拉片。 |
| 06:37–13:48 | 以《大逃杀》《雪国列车》《电锯惊魂》《赌博启示录》《弥留之国的爱丽丝》《西部世界》等说明“游戏类”选材并不新；社会阶层隐喻是老师的解读。13:02起明确这是选材/世界观维度，与前课故事类型不同。 |
| 13:50–19:29 | 游戏类的组成：相对封闭空间、参与者（庄家/玩家）、规则、奖励与惩罚。规则是核心，它应把现实社会规则放大、压缩或作比喻；以教育淘汰、媒体围观、数据监视说明。 |
| 19:34–31:31 | 扩展为“强设定”：主角超能力，对手怪物/鬼/外来力量，时间和身份变化，游戏规则。时间变化包括穿越、交换、倒流、静止、不死、循环、蝴蝶效应等。岔讲市场和预算后仍说现实题材可以继续写。 |
| 31:38–38:32 | 强设定容易形成一句话卖点和开场吸引力，但规则也会限制后续行动空间，容易在长篇中耗尽。用《鱿鱼游戏》人物与表演细节解释如何补充持续可看性。 |
| 38:35–44:55 | 关于评价作品“不要造神”的岔讲：既看优点也能讨论问题，勿把个人喜爱当作作品没有缺点。 |
| 44:56–48:28 | 归纳强设定优点：抓眼、对抗清楚、看点集中；风险是后劲不足。规则需连接一般人的希望/恐惧及可理解的现实经验，《时间规划局》把时间直接作为财富是示例。 |
| 48:35–59:04 | 超能力、怪物、时间及游戏类分别怎样连接期待。先研究已有代表作，再作局部创新；也允许基于现实设计新规则。庄家与玩家身份互换同样可成为变化。 |
| 59:08–68:12 | 现实题材可从新闻、生活体验及事件集中/巧合中提炼戏剧性；《西虹市首富》说明现实与强设定并非硬边界。 |
| 68:14–72:46 | 再区分选材与故事类型：有鬼/外星力量仍可写伙伴之情等。穿越要生成“大展拳脚”的期待或“不适应新环境”的担忧；仅把超市营业员平移成古代卖菜者，没有新增戏剧压力。 |
| 72:47–74:00 | 正式布置自己的游戏类题材方案。 |
| 74:03–80:45 | 讲一名不具名学员把作业获赞误解为将被拍摄/购买的旧事。说明无法读完所有作业、课程题是练习，口头肯定不构成投资或拍摄承诺。 |
| 80:46–81:47 | 重申设计游戏类小故事，旧穿越/超能力题可补练；强设定和现实题材都要学，提醒做作业。 |

## 前课依赖与当堂限制

- 13:02–13:45及69:47–71:06明确依赖前课的十种故事类型：本课的世界观/选材分类是另一维度，不能追加成新的斯奈德故事类型。
- 44:56–48:28、71:09–72:46延续第30课的观众期待/担忧：特殊设定要改变观众追看某个行动的原因，不能只换一个奇观包装。
- 48:48–49:03回指“能拥有一种超能力，你要什么”的旧题，要求没做者补做；69:28后回指“穿越只能带一件东西”；本课没有确认它们最初出自哪一课，不能自行补课号。81:02又以“也可以去琢磨”建议补练。
- 57:53–58:26并未禁止原创玩法：可以创新，但需连接现实经验。31:15与81:29明确现实题材仍有价值；不能整理成所有项目都该改强设定。
- 老师宽泛地把强设定称作“魔幻现实主义”；这里保留他的课堂用法，不将其等同文学研究中的严格术语。

## 老师明确作业

**新作业：构建一个自己的游戏类题材提案/方案。** P58 72:47–74:00；80:53–81:02补称“小故事”，81:38–81:45提醒。

先确定要映射的社会规则，再设计游戏规则、空间、参与者、奖励和惩罚。可选阶层/贫富差距、民族隔阂/种族冲突、教育体制或自己的其他方向；这些是举例，不要求全部写进同一篇。课堂前段还区分庄家和玩家，可帮助理解参与者，但没有要求统一人数。

必要机器原文：

> 73:18–73:24：“首先设计这个规则，因为这个规则需要是社会规则的比喻。”
>
> 73:53–74:00：“给我构建一个提案，构建一个方案……这个是这节课的作业。”

[73:57原视频字幕](../资料附件/lessons-18-34/frame-checks/p058-at-4437s.jpg)确认“构建一个方案”。老师没有规定字数、期限、交稿渠道、完整剧本或六项提案模板；第19课的正式提案结构不能自动变成本次硬要求。74:19起也明确无法逐份读完所有学生作品，没有承诺本题逐稿讲评。

**条件补做：没做过旧超能力题的同学补做。** P58 48:48–49:03：“假设你可以拥有一个超能力，你要啥……没做过的回去补一补。”这是旧题补练，不是另一道全新命题；无新增格式或提交要求。

## 核读限制

机器稿中作品名、人名有误写；只在语境明确时作常见片名归一。课堂关于文化群体、市场比例、恐惧统计等属老师当时观点，没有核验为一般事实。《西部世界》停播时点、《疑犯追踪》季数及现实技术已完全达到预测犯罪等口述未核，不能作为可靠作品史/科技事实沿用；对未来续季的判断是录课时预测。《北京折叠》只保留为例子，不沿相邻口述擅自归给刘慈欣。
