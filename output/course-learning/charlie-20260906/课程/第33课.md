# 第33课｜怎样克服拖延症

原课范围：[P59](https://www.bilibili.com/video/BV1eE411F73t/?p=59)，42:16。已完整逐段读过[机器全文](../转录/P059.md)，未逐句听校；源文件、CID与哈希见同名JSON。本卡记录写作课内容，不把老师的心理成因解释当临床结论。

## 实际分节与目标

| 源时间 | 实际教学内容 |
|---|---|
| 00:10–03:34 | 解释停更三个月是在带训练营，区分公开课与训练营；后者强调商业可看性、实操及完整毕业剧本的诊断。 |
| 03:36–06:39 | 从自己选项目/编剧的经验谈完成度：一部未拍的完整剧本或完整小说也能证明写完的能力；提醒训练营学生不要只听课而不做毕业作品。 |
| 06:40–09:01 | 录课时期教务：网站承接招聘、交易、资料、答疑，便于留存问答。板书写 bianjuke.cn；未访问核验，不把当时招生/网站安排当现在服务承诺。 |
| 09:03–13:44 | 训练营观察到写作纪律不足；批评用“未准备完、追求完美”为不动笔的理由。把“解放天性”解释为自然、客观承认问题，并回指主观投入/客观抽离。 |
| 13:45–21:13 | 老师以对延迟满足不确定、偏好即时反馈解释拖延，用短视频、游戏和影视作品很久才见观众作类比，再引出七个方法。 |
| 21:15–25:52 | ① 奖励：大目标奖励具体化；小奖励频繁化，给阶段完成制造即时正反馈。买车是老师个例，冰淇淋等是小奖励示例，可按个人条件调整。 |
| 25:54–28:44 | ② 拆解任务、做计划：从接任务当天拆，不以自己单日最高产量倒推最后几天冲刺。用30万字/20天/每天1.5万字说明这种拖延式计划的问题。 |
| 28:45–31:35 | ③ 关闭干扰：写作时关闭手机干扰、短视频和游戏，或调工作模式；自己的游戏生涯回顾使其意识到累计耗时。 |
| 31:37–33:27 | ④ 十分钟法则：先说服自己写十分钟，以开始工作降低对困难的预估、进入状态。 |
| 33:28–34:36 | ⑤ 先写最爱的一场戏：尚未完整构思也可以从人物/环境已催生、最想写的一段对抗动笔，辅助十分钟启动。 |
| 34:37–37:46 | ⑥ “为了谁”：若替别人做事更容易投入，可把写作关联到自己在意的人，训练营中老师也用“为了老师写”作为激励。 |
| 37:47–40:14 | ⑦ 找搭档：共同写一部作品，或各写各的、交换意见和督促；可以跨城线上联系，不限定必须夫妻/同城。 |
| 40:17–42:11 | 七项只是表层方法，长期希望提升写作能力、让创作过程本身产生乐趣与反馈；收课。 |

## 前课依赖与边界

- 09:50与19:38后说此前已谈过拖延、动物性/社会性等，本课没有指出原课号。13:08–13:34回指“主观投入、客观抽离”，用来解释承认写作困难。
- 11:23–11:35把完美放到行动中逐渐改进，而不是等一切准备好才动笔；33:51后允许先写最喜欢的一场，不要求完整思路之后才写正文。
- 28:10–28:28老师建议职业写作每天不超过四小时、业余两小时即可。这是个人工作方法建议，既不是全班作业时长，也不能作为每个人的硬性上限。
- 39:29–40:08明确搭档可以不写同一部作品，也可以不在同城；不要替本课增加组队、共享署名或提交搭档合同要求。

## 建议实践与回收情况

- 21:15–25:52：按自己的条件设具体完成奖励与频繁阶段奖励。
- 25:54–28:44：把已有项目拆成每日可执行量；示例“30万字”“700多场”不是规定。

- 34:37–40:14：试着找到在意的受益者/期待者，或能交换意见、相互督促的搭档。

## 核读限制

“拖延就是懒”“成功者都不拖延”、动物性/基因解释是老师的课堂判断，不作为心理学事实或对个体的诊断。38:22后的学员伴随抑郁、找搭档后恢复产出的叙述只是个案回忆，不能推成抑郁症治疗方法。项目周期、按字报价、市场缺口与招生状况均为录课时经验口述，未作为现行行业统计核验。
