# 第11课｜类型片

原课：[p22 11.1](https://www.bilibili.com/video/BV1eE411F73t/?p=22)→[p23 11.2](https://www.bilibili.com/video/BV1eE411F73t/?p=23)→[p24 11.3](https://www.bilibili.com/video/BV1eE411F73t/?p=24)，约86分06秒。

本课把《救猫咪》的十类理解为十种故事创作思路。重点是：自己的故事接近某种思路时，应特别检查哪些关系；一部电影可以并用、先后使用多种思路，不必硬塞进一个互斥类别。

## 十种故事思路：按老师实际解释

| 类型与位置 | 本课需要抓住的关系 | 课堂例子／区别 |
|---|---|---|
| 金羊毛｜p22 28:21起；p23 00:04–03:04 | **路径、团队、奖励**。寻求目标的路径也是人物成长过程，奖品应明确、值得追逐。 | 《绿野仙踪》《西游记》《心花路放》。从劫匪视角组织银行任务，老师归入寻宝思路。 |
| 爱情／情感｜p23 03:07–12:24 | **双方强烈需要彼此，却受到不能在一起的阻隔**。原先说“残缺者＋零件＋沟”，老师进一步改成双方互相补足。 | 包括恋爱、友情、亲情；《泰囧》《泰坦尼克号》接续上课双主角分析。 |
| 超级英雄｜p23 15:21–16:11 | **能力、命门、对手、使命**。 | 直接回顾第9课已讲的英雄人物。 |
| 鬼屋｜p23 12:25–15:20；p24 18:40–21:58 | **逃不出的空间、威胁力量、自己招致问题的“原罪”**。关键是确实无法离开，不是仅给场景取名叫鬼屋。 | 《泰坦尼克号》灾难段、《电锯惊魂》《侏罗纪公园》。老师口称“超自然力量”却也举海水和冰山，本课用例实际扩大到致命威胁。 |
| 侦探｜p23 16:16–20:31 | **观众未知的秘密、带观众探秘的人、探秘中的自我牺牲／选择**。 | 同一银行题材若改为警察查一宗无痕盗窃，观众随其揭秘，便与劫匪寻宝的讲法不同。 |
| 如愿以偿｜p23 20:33–24:57 | **有共情的愿望、实现愿望的规则／代价、得到教训**；老师强调最后重新认识眼前生活。 | 回收第1课幻想；《西虹市首富》《大话王》《冒牌天神》《夏洛特烦恼》。 |
| 麻烦家伙｜p23 24:58–27:18 | 老师建议理解为“家伙遇麻烦”：**无辜小人物、突然降临的麻烦、生死考验**。 | 可以是喜剧，也可以是营救故事；题材与故事思路不是一回事。 |
| 变迁仪式｜p23 27:20–31:42 | **寻常问题、逃避／过激处理、最终回归面对问题**。 | 《录取通知书》《触不可及》；接第4课从过激行为突破故事的思路。 |
| 愚者成功｜p24 00:03–03:23 | **被看作不适应环境的“愚者”、一项大事／伟业、保留自身特点的变化**。 | 《阿甘正传》《律政俏佳人》。先尝试别人方式，最后保留自身长处取得成功；老师也承认它与小人物遇大事等相近。 |
| 被制度化｜p24 03:26–07:30 | **有约束力的群体、个人与群体之间的选择、抗争与牺牲**。 | 《飞越疯人院》《教父》；选择可以是离开群体，也可以投身其中并付出代价。 |

## 课堂示范怎样帮助判断

**同题材换视角，故事责任会变。** p23 18:06–19:36对比两种银行故事：盗贼作为主角，观众知道他们如何寻找并得到目标，重点在任务路径；警察面对一个观众也不知道答案的案件，重点在揭开秘密。这是课堂对照构想，不是新作业。

**类型之间可以并用。** 《泰坦尼克号》既有相互补足又不能相守的情感关系，也有逃不出船只的生死威胁。老师据此坚持称“十种故事思路”，并没有要求先把电影分到唯一类型才开始写。

**检查要点有没有被事件真正建立。** 《半个喜剧》的批评集中在相互需要和阻隔；未具名别墅恐怖片的批评集中在“为什么不离开”。这些是老师对作品的判断，课程没有展示作者原稿、修改过程或观众调查。

## 作业与课堂建议

**明确新作业：全文机器稿检索与阅读未找到明确布置，未逐句听校。**

有一项直接面向自己稿件的检查建议：p24 18:31–18:39，ASR“看一下你的故事，大概属于哪种类型……看一看它这几种元素，你有没有完成任务”。可用上述重点检查现有故事，但老师未指定必须使用哪份旧稿，没有另交类型分析表、重写故事、字数、期限或后续逐份讲评的要求。“回头统一举例分析”（p23 20:25–20:30）在本课后段的电影分析中展开，不是承诺点评这次新作业。
