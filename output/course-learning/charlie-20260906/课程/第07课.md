# 第 7 课｜拿事儿说话

- 原课范围：p14《第七课-拿事儿说话7》，约 19 分 45 秒。
- 原课入口：[p14](https://www.bilibili.com/video/BV1eE411F73t/?p=14)。
- 学习目标：把此前约1500字的八要素故事明确为“梗概”，学会向大纲推进；把抽象描述变成观众能看到的事件，而非只是增加字数。

## 按原课学习

| 顺序与位置 | 实际讲授内容 | 学到这里应弄清什么 |
|---|---|---|
| 00:03–02:55 | 从插入的格式课回到主顺序：创意→梗概→大纲→剧本。此前1000–2000字、约1500字故事就是梗概；大纲通常称“万字纲”。说明两者差别是质的变化。 | 已有梗概继续用，不能只把它描写得更长来冒充大纲。 |
| 02:56–06:48 | 用“老李外表冷淡、内心狂热”说明仅在梗概中的判断观众看不到。大纲必须通过事把设定做出来；让人物直接自我介绍也未必成立。 | 检查每项重要设定能否由一件事表现，否则到剧本里就没有可见依据。 |
| 06:49–09:59 | 引入三幕“建置／对抗／解决”，以100分钟电影的25／50／25举例；将对抗拆成推进与转折，得到四段。 | 这一段的目的在于定位事情放在哪里，不能只背成泛泛的起承转合。 |

| 17:55–19:37 | 按四段、五关键事件定位，以八项观察每个阶段的发展变化；形成表格，之后继续细化为大纲。结尾让大家回去比划这个表。 | 把现有梗概中的描述落实到关键事件，并为后课细分保留空间。 |

## 前课材料怎样续用

本课开头给出直接证据（00:16–00:49）：此前写的1000–2000字、约1500字完整八要素故事，完成后手里就有了“梗概”。本课要求拿这份梗概发展大纲；上一课格式是先插讲，并不意味着跳过大纲。

第3课想殉职的警察再次示范（14:50–17:52）：梗概里可以概述“想殉职”，在大纲中要通过开场事件做出来；人物身份与正负价值在后面的事件中继续变化。这里不是新的学生同题作业。

## 五个事件按原课承担什么

| 原课事件 | 在本课的位置与功能 |
|---|---|
| 开场事件 | 12:04–12:10、14:57–15:21：把主要人物设定做给观众看。 |
| 激励事件 | 11:18–11:29：从建置进入推进，打乱原状态；承接第4课干扰事件。 |
| 转折事件 | 11:31–11:34、13:05–13:27：事情变化，老师用一次动作失败后的二次动作解释；明确说这是他的教学性解释。 |
| 危机事件 | 11:38–11:41、13:29–13:35：把故事推到最终必须解决的危机。 |
| 高潮事件 | 12:12–12:45、13:36–13:42：主角如何完成最后反击／解决，释放此前积累的问题。 |

横向是四段进展、五关键事件定位；纵向仍观察身份、欲望、动作、核心问题、障碍、结果及正负价值。原画面见[18:52板书](../资料附件/lessons-01-17/frames/p014-1132.jpg)。老师画的是教学示意图，具体比例和表格分隔不补造成另一套强制格式。

## 老师明确的课后动手要求

**记住本课表格，回去用自己的故事比划、尝试。** 其教学任务是把已有八要素梗概向事件大纲推进：以五件主要事件作骨架，查看八项在不同阶段的发展变化。

- p14 18:20–18:53，ASR：“五件事情作为……横轴上的股价”“八要素……列为纵轴”“在每一个小方块里面……让他们的发展变化”“得到一张表格”。
- p14 19:28–19:35，ASR：“我们下节课再详细说”“记住这个表格啊，自己回去比划比划”。[19:33原字幕](../资料附件/lessons-01-17/frames/p014-1173.jpg)核为“记住这个表格自己回去比划比划好吧”。
- **交付要求**：原课称大纲通常约一万字，但没有说此次就必须交完整一万字稿；结尾明确让回去试表格。没有提交渠道、日期或表格文件规格。
- **后续讲评／讲授**：明确“下节课再详细说”；未说会逐份公开评表。[第8课](../课程/第08课.md) p15继续细化为十序列，p16–17用警察案例完整示范；结尾另指定这个课堂故事写大纲，暂不要求继续自选梗概。
