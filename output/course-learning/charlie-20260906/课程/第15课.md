# 第15课｜节拍器，以及补讲A／B故事

原课：[p34 节拍器15.1](https://www.bilibili.com/video/BV1eE411F73t/?p=34)（32:11）、[p35 15.2](https://www.bilibili.com/video/BV1eE411F73t/?p=35)（38:22）、[p36 15.3](https://www.bilibili.com/video/BV1eE411F73t/?p=36)（19:07）、[p37 15.4](https://www.bilibili.com/video/BV1eE411F73t/?p=37)（24:07），共约114分钟。全文：[p34](../转录/P034.md)／[p35](../转录/P035.md)／[p36](../转录/P036.md)／[p37](../转录/P037.md)。

这是一节针对反馈补漏的课。p34 14:21–15:14，学生说学完[第8课](../课程/第08课.md)十序列仍原地踏步：“什么事儿呢？事在哪呢？”老师先重提持续记录电影触动和生活细节，再应同学要求解释斯奈德节拍表。p35结尾已经下课，p36–37又补讲容易被误解的A／B故事，原合集把它们一起列在第15课，学习时应接着读完。

## 从十序列走到十五节拍

p34 00:22–14:01先说网课缺乏现场反馈，以及先学常见规律再发展个性的教学立场。03:24–03:31提到收到一两百份作业、尚未看完；**没有指明哪课，也没有展示这些作业**，不能因此认定上一课反写已经被批改。

p34 15:20–19:29讲本课边界：长期解决“没有事”靠素材积累；十五节拍可让分工细一点，但也是一家之说。老师明确担心过早细分会把初学者框死，建议用来找思路。19:38–24:12先复原十序列，再以110分钟、25／30／30／25的四段分配对照。以下是**查理在这堂课中怎样解释这张表**；所列分钟是示例故事内位置，右栏才是原视频回看时间。

## A／B故事：把漏掉的成长补回具体事件

p36 01:10–03:43专门纠正一种学习误解：把A／B叫主线／副线，容易让初学者误以为B是次要的事情。本课使用的含义是 **A＝人物外在经历与行动，B＝内心经历与成长**；want是人物自以为想要、据以行动的东西，need是实际需要补上的部分。p37 04:41–05:41还补一层“大欲望”，例如成名：为了成名而骗取比赛机会是外在做法，真正成长为更好的音乐人则是内在需求。

| 续用／新增案例 | 外在行动与内在变化怎样对应 | 来源与性质 |
|---|---|---|
| 小蝌蚪找妈妈 | 找母亲是行动；在夜行中克服怕黑，在相处中真诚交流，在帮人中获得价值。不同第12课变体的具体need可不同，老师本课明确承认这一点。 | p35 10:48–13:42；p36 05:54–10:54，教师继续解释旧题目，并非十个版本同一条人物小传。 |
| 想殉职的警察 | 为照顾女儿而把钱当答案，想骗抚恤金；在不怕死而立功之后，开始整理仪表、做饭、负责片区，变成更好的警察与父亲。赢回女儿的关系在于B线变化，不是骗赔成功。 | p36 11:00–13:39，明确续用[第8课抚恤金版](../课程/第08课.md)，新增生活细节；不是第3课女儿已死版，也不是学生稿讲评。 |
| 《回到17岁》 | 外部追求球场／奖学金成功与赢回家庭；内在打点是听子女、发现妻子园艺才能，真正作丈夫、父亲。 | p36 13:42–16:31，老师回顾其当时直播看片。 |
| 《定制伴郎》 | 雇假朋友防穿帮与两个人实际建立友情同时发生；职业伴郎自己也缺朋友。一度划清雇佣界限、被问自己结婚谁作伴郎，形成层次。 | p36 16:34–p37 02:25，教师成片分析。 |
| 《摇滚校园》 | 代课赚钱、组织孩子赢比赛；同时更准确理解和传达摇滚精神、保护孩子，成为更好的音乐人。 | p37 02:29–08:54，教师成片分析。 |
| 周星驰系列 | 老师认为小人物的卑微谋生／成名行动与更大的助人目标被拉得很开；用《功夫》《武状元苏乞儿》《喜剧之王》等说明跨度。 | p37 08:56–18:07，教师作品解读；由作品推测创作者心理属个人感想，不能作心理事实。 |

**落实到已有大纲的方法**在p36 03:44–04:52、p37 18:24–23:48：先看A线上做了哪些事，再单拉B线，逐点写人物内心怎样被触动、改变；能依附现有事件的就合在一起，某个成长节点没有载体时再补事件，最后检查B是否完整。p37 20:47–23:39再接回[第13课](../课程/第13课.md)独立人物关系线：电视剧关系复杂时值得单列，电影视情况；老师介绍过还单列价值线的做法，却没有要求每人都做四张表。
