# 用这套资料处理一份故事

**当前开发顺序（2026-09-09用户纠正）：** 先完成34课及33补充的贯通课件，再开展业务实作和GPT-6横向对照；不按下面的旧调用说明继续逐课试做。课件整理期间仅整理与核对资料，不生成新故事、执行作业或启动对比。现有探索结果保留。[本轮课件约定](全课课件/整理约定.md)。现已交付[四卷完整课件与导读](全课课件/README.md)、[作业和案例接续](全课课件/作业与案例接续.md)；本次先交付资料，不自动重启旧对比。

这是依据查理公开编剧课程整理的资料和候选操作方法。完整讲解在四卷课件与67章连续讲义中，逐课页提供来源时间与作业；方法页仅为早期候选。入口已完成一份完整故事的真实试用与返工，部分方法尚未专项试用；不要对用户声称已获得稳定编剧或营销能力。

先读用户任务、已有材料和稿件，确定此次要交什么。把已有稿当作起点；遇到问题再读取相关方法及其案例，不要求用户从头上课，也不把整套课程一次读入上下文。

长文按段读取，以模型收到的工具返回为准；返回含 `truncated` 就补读缺段，不能把命令成功或界面完整输出当作已读全。已有原生工作文件应分别取出所需阶段正文，不整份打印；一段太长就继续拆小。

独立试验使用关闭自动记忆的新原生任务，明确列出当轮材料。同题返工带有旧稿与具体反馈，单独记录这些输入，不能与首次创作混为同条件测试。

业务试验的默认基本对照是新建、`fork_turns=none` 的GPT-6子智能体，只给同一业务简报，不提供项目历史或课程方法；额外输入与人工帮助单列。产品首次使用就应有用，课程和试验由研发承担，不能要求客户先积累学习和试错。完整北极星与边界见[产品交付与开发验证约定](../../business-methods/产品交付与开发验证约定.md)。

先辨认整体问题和局部问题。若反馈是“中心思想看不出来”“事情不少却不知道在讲什么”，读取[课程核心方法论](课程核心方法论.md)，回到主要人物、行动、关系和结尾作整体取舍；不能只加描写、检查算术或列“亲情/匠心”标签。已有清楚重心的稿件直接处理当前问题。允许先写故事再发现主题，不要求每个故事预先立道理、强造人物转变或悲剧代价。

| 当前实际问题 | 先读 | 本次通常应得到什么 |
| --- | --- | --- |
| 细节已有，但整篇要表达什么仍不清楚 | [课程核心方法论](课程核心方法论.md) | 说明正文实际支持哪种理解，选择整体方向，并依任务调整主要事件、关系和结尾；分析说明不能替代正文。 |
| 只有一个材料或想法，还没有从头到尾的故事 | [从材料写完整故事](方法/从材料写完整故事.md) | 有明确因果和结果的完整线性故事；具体形态按任务决定。 |
| 人物处境都写清了，但主要靠说明，没什么事情发生 | [让信息变成事件](方法/让信息变成事件.md) | 改写后的完整场面或相关段落，信息由行动及其后果呈现。 |
| 因果已清楚，但没有继续读的理由 | [让读者想继续看](方法/让读者想继续看.md) | 能建立、发展并回应具体期待的连续正文。 |
| 场面已有动作，但很直给，换谁都一样 | [把一场戏写得具体](方法/把一场戏写得具体.md) | 贴合当前人物、有变化且承接前后的具体场面。 |
| 有完整稿，但动机、发展、关系或结尾存在问题 | [沿因果返工](方法/沿因果返工.md) | 同一稿件的修订版及必要的前后调整。 |
| 用户要按原课学习或交作业 | [全套目录](全套目录.md)、[原课作业](原课作业.md) | 对应原题的实际交稿；先分清新作业、旧作业回顾、课堂讨论和观看建议。 |

方法页是项目整理的操作顺序，不能冒称老师原本给出了同样的固定流程。遇到定义、案例版本或作业要求不确定，沿方法页回到课程页和原视频时间；若当前资料不足，明确缺口，再决定补资料或采用标明的创作假设。

执行原课作业时，按原题保留交付形态：幻想、梗概、大纲、看片、自查标记各有用途，不统一扩写成故事正文。全课学习顺序与换题位置见[学习与作业路线](全课学习与作业路线.md)。

写作时给用户作品正文。工作笔记可以保存构思和修改依据；八要素、序列、主题或情绪标签不能代替本次应交的故事。作品需要视听设计时另行发展画面、声音、音乐、配音、表演和节奏，编剧课程资料不能自动补全这些能力。

在第七版系统中，继续使用原生工具读取材料、写文件，并由 `marketing_work` 保存本次工作的研究、方向、作品及续用关系。按实际工具返回的参数和路径使用，不自行伪造作业链文件。普通文件是材料和成果，原生 App Server 仍负责模型与工具运行。

保留初稿、实质反馈、修改稿和仍未解决的问题。文件写入、工具接续和模型自评各有用途；读者是否理解、想继续看，仍需要作品层面的实际反馈。

当前具体试用与未解决问题见[实作结果](实作结果与边界.md)。2026-09-09整体方法已用于《最后一针》v4、具体反馈及v5；独立模型能读到父女关系，但v5再次失约与作者“开始说实话”的判断不一致，尚未获得用户或真人读者的质量认可。不继承任何局部复核的通过结论。
