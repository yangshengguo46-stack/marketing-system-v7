# 这套课到底在教我们怎样写故事

这套课可以贯穿起来理解为：**从对人的观察出发，让一个具体的人为自己在乎的东西行动；事情的发展检验他的办法、关系或信念，结果让观众对这个人及其处境产生理解和感受。** 构思、结构、场面、对白、悬念，都在帮助这个过程成立。

这是本项目结合全课的归纳，不是老师说过的一句总纲，也不是所有作品必须遵守的公式。此前我们整理出了课程目录和五个局部方法，却没有把这层关系放进实际创作。于是能检查鞋在谁手里、时间算没算对，却没有充分回答整篇为什么值得讲。

## 人物、事件、主题是一件事的三个方面

[第2课](课程/第02课.md) P006 01:38–08:19先讲三者关系，再在08:19–16:54拆八项。人物在乎什么，决定他会采取什么办法；办法遇到的阻碍与后果，使他的选择有了分量；故事怎样处理这些选择，才呈现作者看待这件事的角度。

这里有几个容易混在一起的东西：

| 层面 | 以修鞋故事为例 | 它还没有回答什么 |
| --- | --- | --- |
| 题材 | 修鞋匠、父亲、女儿演出 | 为什么从这个人的生活中挑这十分钟来讲。 |
| 话题范围 | 亲情、责任、承诺 | 围绕这个话题，作品具体在追问什么。 |
| 行动悬念 | 能不能修完鞋并赶上演出 | 就算知道他赶上了，我们对人或关系多理解了什么。 |
| 整篇追问 | 例如：他习惯用怎样的方式回应别人的期待，这次还行得通吗？ | 这是一个可发展的问题，仍要由具体事件来回答。 |
| 主题倾向 | 例如：可靠需要怎样的行动，单靠答应够不够？ | 这只是候选方向，不能贴上去就说正文已表达。 |
| 观众感受 | 担心失约、理解难处、看见彼此在意后的松动 | 写人物着急或感动，不保证读者产生同样感受。 |

“整篇追问”是这里用于整理的方法用语。原课八要素中的“核心问题”更接近人物能否完成动作的持续悬念，不能悄悄将它改成主题问题。

老师的“主题”用词也有不同层次：第2课主要连到作者价值与选择结果；[P081](补充/P081.md) 49:18–49:47又把主题解释为话题范围，把影片的结论另作区分，例如“完美人生”与“没有完美的人生”。保留这个区别，才不会把“亲情、匠心”两个标签当成完整的表达。此处只是记录教师对《蝴蝶效应》的解释，不替原作者认定唯一意图。

作为本项目的写作边界，作品可以表达朴素的判断，也可以呈现尚不能轻易回答的困境。不要求最后说出大道理，不要求所有读者总结成同一句话。比较有用的检查是：读者能否指出**具体哪一次选择、哪种关系或哪个结果，使自己产生了这种理解**。

## 用课程中的一条完整联系来理解

[第15课](课程/第15课.md) P036 11:00–13:39再次讲想殉职的警察，沿用的是第8课妻女仍在、想留下抚恤金的版本。它和第3课丧女版本不同。

在这次讲解里，人物把钱当作照顾女儿的答案，走向骗取抚恤金的办法。外部故事围绕他的行动、立功和后续遭遇展开；老师同时讲他开始整理仪表、做饭、负责片区，变成更好的警察和父亲。于是，照顾女儿这件事的含义，不再只由钱的多少决定。

这几步相互作用：

1. **他在乎女儿**，使原本反常的行动可以被理解。
2. **他对怎样照顾女儿有自己的判断**，这个判断使他选了特定的办法。
3. **事情让他经历新的关系与责任**，这些经历通过具体行为表现。
4. **人物与女儿关系的发展，要从新的行为得到支撑**，不能只在结尾宣布“他懂得了父爱”。

课程在这里示范的是外在行动与内在变化怎样连起来。上述四步是我们的归纳；原课没有在这一段给出完整成稿，不应自行补成老师已展示过的全部情节。

这也解释了[第15课](课程/第15课.md) P037 18:24–20:46的实际改稿办法：先看人物做了哪些事，再单独检查内在变化的过程；找到已有事件可以承载的位置，确实缺少载体再补事件。所谓A、B，是看同一个人经历事情的两面。

另一种情况是人物坚持已有信念。[第21课](课程/第21课.md) P044 35:07–36:38建议从价值与态度来写人；37:30–40:47以安迪和瑞德对希望的不同观点作例子，再讲长期挖掘、不断写信争取改善图书馆的行动。这里真正有用的是“相信什么、以什么态度持续做什么”的联系。只写“安迪坚毅乐观”看不到过程；只有一张“希望”主题卡，也解释不了那些行动。片中的具体年份和金额不在这里采用，教师口述不是逐镜事实核验。

## 整体方向会改变事件的选择

[第24课](课程/第24课.md) P050约67:20–74:39对《战国》的推演，更能说明“想讲什么”会怎样改变故事。老师依次讨论不同方向，而不是只给原来几场戏增加动作：

| 选择的方向 | 人物和事件随之怎样改变 |
| --- | --- |
| 爱情 | 转向孙膑与庞涓妹妹的关系，让爱情、亲属和国家立场构成实际阻碍；要有相识、需要与选择的过程。 |
| 兄弟情 | 集中孙膑与庞涓，从同门的信任、利益与分歧，发展到伤害和对抗。 |
| 个人成长与复仇 | 以孙膑复仇为主要行动，讨论如何从个人仇恨发展到不同的目标与自我认识。 |

这些是教师的改编提议，未被实际重拍验证，也不是原片主创的构思实录。可以学的是：**当表达重点改变，谁站在中心、什么阻碍重要、哪些事必须发生、结尾回应什么，都要一起调整。** 只更换一句主题文案，原来的事件不会自动获得新含义。

## 全课各部分怎样服务这条主线

| 课程位置 | 在整个创作过程中做什么 |
| --- | --- |
| 第1—4课：材料、三要素、构想入口 | 从观察、愿望、恐惧和共情找人；从人物、事件、悬念等任一可发展的入口开始。先找到一件想继续探究的事。 |
| 第5—8课：故事、事件、大纲 | 把构想写到结果，再用事件表现原本的概述，观察人物和价值在不同阶段怎样发展。第7课的横向事件与纵向八项是同一故事的两种观察方向。 |
| 第9—13课：配角、类型、多人物与长篇 | 让其他人有实际作用，让关系发展影响行动；类型提供经验，篇幅变长仍要有事件和人物联系。 |
| 第14—19课：场面、AB、信息与提案 | 让整体诉求落到具体戏。悬念决定何时让观众知道什么；对白和场景承担当下行动；提案帮助对方理解作品。 |
| 第20—29课：拉片、情感情绪、关系与命题返工 | 检查观众能否进入人物处境，冲突是否作用于人物与关系；通过实际作业问题回到整体发展。 |
| 第30—34课及补充拉片 | 发展持续期待、题材规则与具体情节，辨认例外；每场的写法仍要知道自己想表现什么、怎样接前后。 |

这张表说明课程之间的联系，不改动原始课序或作业。[原课路线](全课学习与作业路线.md)继续负责准确的题目、交稿形态与回收位置。

## Agent实际怎么用这条主线

**先读材料和完整稿，找已经存在的重心。** 能用普通话说明主要在跟谁、等哪件事、在意哪段关系，就先从这里发展。初稿已经有意味时，不要为套方法另造缺陷或强迫人物蜕变。

**整体不清时，先提出一个可被事件检验的方向。** 在工作笔记中，用一小段话说清：这个人为什么这样做；这件事触及了他什么在乎的东西；后面的发展会让哪种判断得到检验，或让哪段关系被重新看见。可以从已有故事中发现这个方向，也可以有多个候选后作取舍。它不是正式写作前必须过的审批表，更不是用户需要填写的课程问卷。

**沿开头、发展、结尾检查同一件事。** 开头给观众什么期待；中间有哪些行动改变处境、关系、判断或我们对人的认识；结尾实际回应了什么。若从头到尾只有“他一直很认真，最后事情办成了”，要判断这是否就是想要的朴素观察；如果想表达的是变化或两难，当前事件便还不够支持。

**根据缺口调整事件，再改善细节。** 中心关系未成立，补让双方发生关系的事情；某个判断从未受检验，调整真实会使人物为难的选择；结尾只结束任务，却没回应主要关系，就回到前面看遗漏了什么。用[因果返工](方法/沿因果返工.md)处理前后影响，用[具体场面](方法/把一场戏写得具体.md)发展该场的表现。不要把所有补丁堆到结尾。

**交付作品，让读者从正文形成自己的理解。** 请读者说哪里在意、哪里困惑、结尾带来什么感受，再回看是否有具体事件支撑。理解不同可以讨论；完全需要先读作者分析才能看见重心，则仍有问题。最终交付始终按任务要的正文、梗概或剧本，构思说明只保留必要部分。

## 三个不能省掉的边界

**不要求先有道理才准写故事。** [第21课](课程/第21课.md) P045 23:42–27:02提醒少说理，先把什么人办什么事讲精彩；有故事而暂时没想出主题也先写。第4课的五种入口同样允许从人、事、悬念或环境进入。这里的整体梳理可以发生在写前，也可以发生在改稿时。

**不要求主角必定改过或付出悲剧代价。** [P092](补充/P092.md) 41:20–42:00保留坚定、偏催化剂的主角例外。人物可以坚持、影响别人，也可以让观众逐渐看见其原本的样子。两全、开放或安静的结局都需要看前文是否支持，不为了“主题深刻”硬加死亡、失约或强行反转。

**主题清楚仍不等于好看。** 第24课41:55–64:47区分结构、看点、情感、情绪；第34课03:11–05:10举“知道要表现母爱，仍写得直白”的例子。整体有重心之后，具体行动、观察、表演和视听表达仍要继续发展。

## 用当前作品检验我们是否真懂了

《最后一针》v3已有修鞋的认真和父女相见的温暖，但从“怕两边都辜负”到“鞋修完、演出也赶上”，中间尚未充分发展一个统率全篇的人物或关系问题。此前返工修正了时间，却也移除了最初设想的迟到代价；记录了这个变化，仍没有重新完成整体取舍。

具体诊断与后续构思方向见[《最后一针》中心问题复盘](练习/最后一针-中心问题复盘-20260908.md)。本轮先修课程方法的缺口，保留原稿，没有把这些新步骤写成“已经实跑好用”。
