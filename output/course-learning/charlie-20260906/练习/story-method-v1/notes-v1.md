# 小三角公式、关键词与选择说明

## 三角结构

```
        表达（顶点）
     陈师傅在意女儿今天的独唱
       /                    \
  直给写法              绕到另一侧
  看表催客             格外慢格外细
  明说赶着             不催不提
  去听女儿               做分外的事
       \                    /
        回到表达（底边）
   针扎偏 → 找零手忙
   → "早点收了" + 收摊骤快
```

## 三角公式与关键词

**想表达什么：** 陈师傅在意女儿今天的第一次独唱，想准时收摊赶过去。一个父亲压在心里的在意。

**原本会怎样直写：** 师傅不停看表，催顾客"你那只鞋到底修不修"，明说"今天女儿有演出我得赶过去"。急就直接写急——顺撇，一步直达诉求。

**去反向的一侧怎样绕一下：** 绕到急的反义——慢和细。不催、不提女儿。磨底、涂胶、等胶干，每道都比平时慢半拍。还给没坏的鞋打蜡，做顾客没要求的事。旁人问起女儿演出，语气像在说一件跟自己没关系的事。表面是一个有大把时间、对每双鞋都一丝不苟的老匠人。

**再如何回到原诉求：**
1. **针扎偏了**——二十年修鞋的老师傅，缝第一针斜穿出鞋帮侧面。不是手不稳，是心已经在别处。这一下露出他压住的急。
2. **找零手忙**——捻出一张五块又放回去换三张一块的，手上的稳当维持不住了。
3. **收摊骤快**——鬃刷剪刀锥子一件件归位，动作忽然快起来。"早点收了"一句话和动作一起把那份压着的急切彻底透出来。

回到表达时点到为止：不写"他心里想着女儿"，不写"父爱如山"，靠行为裂缝让在意自己显出来。

**关键词：** 在意、压着不说、格外仔细、针扎偏、收摊骤快

## 选择说明

### 为何选这个三角
- 另一侧（格外慢格外细）和表达（急着赴约）构成真正的反义，不是换职业换地点。
- 回到表达靠的是行为自身裂缝（针扎偏），不是靠旁人揭穿或台词解释，符合"让在意从行为中显露"。
- 小小尴尬落在打蜡那一下——顾客觉得多余说"那只不用弄"，是尴尬不是冲突，符合轻松含蓄。
- 女儿不出现，师傅不牺牲赴约——他只是压着急把活做好，然后利落地收。

### 老周的作用
老周路过问一句"你闺女今天不是在活动室唱歌吗"，是让读者在针扎偏之前就知道师傅为何反常地慢——必要背景在读者判断所需时到达。没有老周，读者在针扎偏时会迷惑：这个人到底急不急？老周的问话和师傅的淡然回答"知道，六点半"形成反差，让读者先感到"他在压"，再看到"压不住"。老周不需要停留，一句话就走，不占篇幅。

### 尚未知
- "针扎偏→急切泄露"能否让实际读者感受到师傅的在意，未经目标读者验证。
- 单场约800字能否同时撑住人物、三角转折和线索延续，需通读自查。
- 老周的旁问是否可以由顾客或环境替代以减一人——目前保留，因为他提供的信息比顾客自然提问更合理（社区管事知道社区活动）。
- 方法本身是候选副本，未经本轮完整作品检验；课堂示范的写法与预期也未经读者效果证明。
