# 小三角公式、关键词与选择说明（v2）

## 三角结构

```
        表达（顶点）
     陈师傅惦念女儿今天的第一次独唱
       /                    \
  直给写法              绕到另一侧
  看表催客             不催不提
  明说赶着             按住手上的活
  去听女儿             认真做完（磨底、换胶、打蜡
                        各有工作理由）
       \                    /
        回到表达（底边）
   针扎偏 → 找零停顿
   → "早点收了" + 收摊骤快
```

## 三角公式与关键词

**想表达什么：** 陈师傅惦念女儿今天的第一次独唱，想准时收摊赶过去。一个父亲按住不说的惦念。

**原本会怎样直写：** 师傅不停看表，催顾客"你那只鞋到底修不修"，明说"今天女儿有演出我得赶过去"。急就直接写急——顺撇，一步直达诉求。

**去反向的一侧怎样绕一下：** 不催、不提女儿。把活认真做完——磨底、换软胶底、等胶干、打蜡，每一步各有工作理由，不是无理由地反义拖延。旁人问起女儿演出，语气像在说跟自己没关系的事。表面是一个有大把时间、按部就班的老匠人。

**再如何回到原诉求：**
1. **针扎偏了**——针尖从鞋帮侧面斜穿出来，差了小半公分。手上的活认真做着，心已经走了一步。
2. **找零停顿**——捻出五块看了一眼放回去，换了十块。不是手忙到算错账，是手上顿了一下。
3. **"早点收了"加收摊骤快**——鬃刷剪刀锥子归位，折围挡、卷电线，动作忽然快起来，不再耽搁。

回到表达时点到为止：不写"他心里想着女儿"，不写"父爱如山"，靠行为裂缝让惦念自己显出来。

**关键词：** 惦念、按住不说、认真做完、针扎偏、收摊骤快

## 选择说明

### 为何选这个三角
- 另一侧（不催不提，按住手上的活认真做完）和表达（惦念赴约）构成反差：嘴上淡，手上的活不停，但心从针脚和找零的停顿里漏出来。
- 另一侧的慢有工作理由（底子磨薄需要磨、胶底型弯需要换软的、皮子不打蜡干得快），不是为凑三角让人物无理由地做反义动作。
- 回到表达靠的是行为自身裂缝（针扎偏），不是靠旁人揭穿或台词解释。
- 小小尴尬落在打蜡那一下——顾客觉得多余说"那只不用弄"，是尴尬不是冲突，符合轻松含蓄。
- 女儿不出现，师傅不牺牲赴约——他只是按住惦念把活做完，然后利落地收。

### 老周的作用
老周路过问一句"你闺女今天不是在活动室唱歌吗？头一回吧？"，让读者在针扎偏之前就知道师傅为何反常地淡——必要背景在读者判断所需时到达。"头一回"三个字让正文的"第一次独唱"独立可读，不依赖题面。老周的问话和师傅的淡然回答"知道，六点半"形成反差，让读者先感到他在按住，再看到按不住（针扎偏）。老周不需要停留，一句话就走，不占篇幅。

### v1→v2 修改记录

**1. 找零修正：** v1中20−10应找10元，实际只递3元（少7元），交易未闭合。v2保留捻错停住的动作，但改为换了一张十块递过去，找足十元。代价：失去"手乱到算错账"这一层，但扎偏针已承担"心不在手上"的显露，找零不需要双重证据。

**2. 第二只鞋末段重复意外删除：** v1中顾客中段已说"那只不用弄"，末段却再次意外"这只你没说要弄"——顾客亲眼反对过打蜡，不可能再次意外。v2删去这次重复对话，让装袋、交鞋顺接，"早点收了"移到收工具时说。

**3. "首次独唱"补入正文：** v1老周只说"唱歌"，读者不知是第一次。v2老周台词补"头一回吧"，让正文独立可读。

**4. notes修正：**
- "急着赴约"收窄为"惦念女儿演出"——四点到六点半不构成已知时间紧迫，不说文本已明确呈现"压住的急"。
- 删去"二十年修鞋老师傅"作论据——正文无此信息。
- "读者先感到他在压，再看到压不住"改为创作预期，不断言读者实际感受。
- 师傅的慢有工作理由，不为凑三角做无理由反义动作。
