## 这次能证明什么

由同一真实GLM模型经原生App Server完成取材、初稿、具体返工与保存。初稿不是占位文案，后续也不是仅在提示词中声称已经学会。本文不把模型生成、文件保存或模型编辑意见当成读者效果。

实际使用了“从材料写完整故事”“沿因果返工”“把一场戏写得具体”，收尾还读取“让信息变成事件”。“让读者想继续看”已完成课程来源复核，本轮没有单独使用和检验。一次同题返工不证明方法跨题稳定，更不能证明营销效果。

根据实际错误，只给完整故事方法补了顺序一致性自查，以及用现有原生工具核算、将检查过程留在笔记的提示。第三轮确实执行Python时程核算，并删减了正文中重复分析。没有为此扩建运行设施。

## 记录在哪里

`../run/full-course-v1-events.ndjson`保留同一任务三轮真实JSON-RPC事件；文件名沿首次运行标签，后两轮也在其中。`../run/read-snapshots/`另存实际cat返回的材料版本，避免把后来修订的方法误说成初稿已经读过。

当前原生工作文件只保留最新三阶段；v1/v2的当时状态分别备份在`../run/work-after-v1.json`、`work-after-v2.json`，故事各版单独留存。模型在v2报告中曾误称旧draft还在当前工作JSON里，这个说法不成立，不采信。

所有独立评阅均来自模型辅助编辑，不是老师批改或真人观众实验；字数要求也与旧550—850字片段题不同，不拿两轮直接计算提升率。最终可用性与尚未解决问题见[实作结果与边界](../实作结果与边界.md)。
