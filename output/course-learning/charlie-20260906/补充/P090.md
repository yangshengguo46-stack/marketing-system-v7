# P90｜《肖申克的救赎》拉片（一）

[原分P](https://www.bilibili.com/video/BV1eE411F73t/?p=90)，17:16.59。按原顺序完整读完最终126段[机器稿](../转录/P090.md)，未逐句听校。是P90—92连续专题的第一部分，本P截至屋顶啤酒，不把结尾理解为整堂课下课。文中“电影第几分钟”是教师对成片定位，播放器时间另列。

| 06:08–07:26 | 第3包，约9分钟：新人入狱，瑞德下注安迪先崩溃，给相遇一个具体渊源；瑞德在旧环境的熟练与安迪的生疏形成互补，同时交代环境。回指前课关系建立方法。 |

| 10:47–11:17 | 第7包，约24分钟：洗澡再推进姐妹帮危险，与早餐的小铺垫相连。老师说常规可在第二幕开头正式展开，但早些立威胁也可以。 |

| 12:54–14:56 | 第9包：轻快呈现石锤流转入狱的过程，以“小锤挖墙需600年”打破刚生出的越狱预期。老师认为这是一种先给期待又消解的高手处理；同时回应学生，这是满足监狱生活想象的“游戏时间”。 |
| 14:58–16:11 | 第10包，约31分钟：蒙太奇呈现反复欺凌/侵犯，同属监狱题材的观众预期；游戏时间不等于角色在愉快玩耍。 |

## 明确作业、建议与讨论

**全文机器稿检索与阅读未找到明确布置，未逐句听校。** 04:10–04:29说有条件者记笔记、希望所有人记，重看时可用；没有要求交信息包表、统一数量、截止日期或重写同类完整故事。01:40的“下次碰到这种题材知道咋写”是教学目的，不能改成已发布命题。

14:28–14:56表扬学生把违禁品入狱过程认作游戏时间，是课堂讨论回答；没有学生作业展示或对某一旧题的回收。

## 前课依赖和不能硬化的说法

- 明确回指关系建立的“相遇/渊源/互补”；本片以赌局使安迪与瑞德的相遇具体化，不要求所有伙伴或情侣都复制赌局。
- 09:07–09:49纠偏救猫咪的字面化：尊重死者姓名才是该场被强调的价值动作，[09:16字幕](../资料附件/supplements-p088-p090-092/frame-checks/p090-at-556s.jpg)核到“尊重人的存在”。
- 15:21–16:10纠偏游戏时间字面化，[16:09字幕](../资料附件/supplements-p088-p090-092/frame-checks/p090-at-969s.jpg)明确是观众对影片的基本预期；人物遭遇可痛苦。
- 10:27–10:47允许姐妹帮在第一幕先铺威胁，说明结构分区不是不准跨越的出场限制。
- 13:30–14:27解释石锤“先提示又撤掉”是对成片的信息安排解读；虽然越狱结局未提前持续承诺，眼下的监狱生活、伙伴关系与自由尝试仍提供观看期待。不能据本段反推第30课“可预期”失效，也不能硬说作者必须从开头明说最终计划。
- 整理者与旧课比较：第21课P44 34:01–41:12从希望观念看行动，第22课P47 11:44后从内外自由/AB看高潮，第27课P53 42:38–46:54从瑞德的知情范围看叙述。本P先逐信息包，后两P是否修正这些判断须继续连读。
