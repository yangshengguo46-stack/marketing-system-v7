# 作业与案例怎样接起来

本页读法：先辨认上一阶段留下的材料，再看课程是否明确提出新交付。方法讲解、看片建议、课堂设问、自愿征稿，不自动变成必须提交的新作业。原课完整规格和原时间见[原课作业](../原课作业.md)与[全课学习与作业路线](../全课学习与作业路线.md)。本轮只整理，不执行下表任务。

## 正课的真实接续

| 节点 | 带入与留下什么 | 后续实际关系 |
| --- | --- | --- |
| 第1→2课 | 写自己真实有过的幻想，进一步描述；第2课从幻想回收到愿望、恐惧与素材组合。 | 有明确回收；不是第一课就交完整故事。 |
| 第2→3课 | 三要素、八项之后，先看老师怎样增强一份普通警察故事。 | 第2、3无新的明确交稿；“前十个故事按八项”不是当次交十篇。 |
| 第4→5课 | 五入口择一起笔，写自己的第一份故事；第5课补充约1500字、线性、八项完整。 | 同一任务补规格，不是两份故事。 |
| 第6→7课 | 第6讲格式；第7把前份故事命名为梗概，用发展表试排事件。 | 不是第6直接扩剧本，也不是第7当次交一万字。 |
| 第8课 | 换用老师继续展开的抚恤金版警察，按十关节写大纲。 | 与自选梗概分开；课代表完整原稿未收录，老师现场推演可读。 |
| 第9—13课 | 检查主角、配角、关系、类型、多线与长篇组织。 | 有匿名少年稿反馈，题目归属不明；不能算第8大纲逐份回收。无逐课新增全文任务。 |
| 第14课 | 回看本课两场成片，尽量1∶1反写为环境、动作、对白。 | 《风骚律师》碰瓷与《泰坦尼克号》餐厅；需实际看片，文本摘要不能代交。 |
| 第15—17课 | 细化节拍、A/B与信息；共性讲评后自查和试改已有稿。 | 第17因稿量改群批，不意味着每题每稿验收；不指定唯一旧题。 |
| 第18—19课 | 看开场移动与提案六部分的具体办法。 | 无明确人人交一份提案；方法在需要时应用。 |
| 第20→21→22课 | 自行拉《加勒比海盗》，注意结构与A/B；后课回用特纳与高潮。 | 有明确回指，但未提供整份学生分析或逐场标准答案；原题未点系列部数。 |
| 第22课 | 用自己耳闻目见的家人材料，第三人称写其故事，允许艺术加工。 | 无固定字数或全剧本要求；后两课未确认回收。Agent不能虚构用户家史。 |
| 第23课 | 喜剧专题与学习建议。 | 没有另外的完整喜剧交稿题。 |
| 第24课 | 用《战国》人物信息，爱情、兄弟、复仇三方向择一，也可自找方向，先写梗概。 | 不是三篇全写；课堂速看不足以证明掌握原片全部细节。 |
| 第25—26课 | 情绪自查及多种解释视角。 | 没有必须交情绪表或五套分析的新作业。 |
| 第27课 | 观察指定作品的视角和切换。 | 是看片题，无写作报告规格，电视剧不扩为全部季集。 |
| 第28→29课 | 同一公路故事命题，包含上路、中点调整及“其实都是我”的精神联系；第29收到稿后要求加强有效阻力、改旧稿。 | 明确题目—交稿—共性诊断—改稿链；没有学生原文、逐句批注或修后复评。 |
| 第30—31课 | 回顾期待满足，研究单元喜剧与任务剧。 | 没有新命题；不能把匿名初稿反馈强挂到第29。 |
| 第32课 | 构建游戏题材方案，关键规则与现实问题相连。 | 没有统一字数或完整剧本要求；后续可识别回收未确认。 |
| 第33课 | 七种启动与持续写作办法。 | 训练营毕业剧本属于另一安排，不能移成公开课新作业。 |
| 第34课 | 交小三角公式与关键词，再交一场戏或一段情节，两部分都要有。 | 原课说选典型稿直播，当前材料未展示后续；只交标签不算完成。 |

补充新增练习接在[第四卷](第四卷-补充案例与后期修正.md)相应案例之后。P071需看片积累喜剧实例；P073信息差观察与第四幕扩写分开；P080是选家族人物与人生时期；P082希望与破灭；P083采用第二改编方案；P084自愿商业改写；P085本土鬼屋十人物关系；P088实际统计；P089若干观察与改写思考。各项字数、是否提交等以节点原文为准，不统一成一种作业格式。

## 同名案例也必须分版本

**警察不是一份从第3课一路不变的剧本。** 第3课女儿遇害、希望殉职后继续保护；第8课妻女仍在，求抚恤金留钱，老师在课代表思路上继续现场修改；第15课沿用妻女仍在的思路讲外内旅程，但回顾细节并非定稿；第19课标签例又口述后来不想死反倒死。第8课自身还有转折/再转切点差异。保留每版的动机—事件—结果，才能学会取舍，不能混出一个自相矛盾的通用警察案例。

**十个蝌蚪不是一篇故事的十个段落。** 第12课每换一种讲法，会重写人物能力、妈妈与龟的身份、阻力和结局。它们并未全部发展成完整十序列，部分还有未解决因果。学的是变更一个核心选择以后，其他部分怎样联动；不是把十版最好看的点拼成一稿。

**公路命题示范的两个收束不是一份完成品。** 第28课“见网友”一路推演后，理想自我与身份接纳、家人车祸旧伤投射是不同方案；“其实都是我”要求精神联系，不强迫揭底为鬼魂或幻觉。第29课处理学生稿的共性压力不足，没有提供可重建的具体学生逐句改稿。

**完整电影与课堂改编分开。** 《战国》三条重构、《药神》四种开场、《阿凡达》两种假设、《危情时速》两种改题，都包含老师主动新设，不能作为原片剧情。P073与P081不同结局是版本差别，不能当影片自身前后错乱。

## 后课对前课的约束

“先自我取材”与“别只写自己”并非取消生活：第1—2课积累真切感受，第4、17课防止私人熟悉感取代陌生观众的理解，第22课又明确指定家人并转换视角。需要的是把真实材料变为他人可理解的过程。

“信息节拍”最后要落实为“事件节拍”：第7、16课负责结构与信息任务，P001纠正完成信息就自认完成戏的误学。“人物要变化”也不能压过P092的坚定主角；“增强冲突”必须容纳P071、P084的风格代价；“类型”要连第11、P076、P081的修正；“少前史、旁白”须容纳第18、27与P091的具体用途。

这些不是额外增加的硬门槛。它们提醒后续Agent：遇到方法冲突，回到这篇故事、这个阶段、这一种风格的实际问题作选择，并保留选择依据。完整课件交付后，再用完整作品检验这种判断是否真的比通用模型更有效；本轮没有把整理完成记成能力通过。
