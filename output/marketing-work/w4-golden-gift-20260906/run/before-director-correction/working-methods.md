# 本轮试用的具体工作方法（研究说明，非Skill、非已验证能力）
M1 来源：Christensen Institute，Jobs to Be Done，https://www.christenseninstitute.org/theory/jobs-to-be-done/ 。直接阅读官方说明。研究具体人在什么处境下做了什么选择、想取得什么进展、又顾虑什么；人口标签和商品属性不能替代这段过程。其公寓案例从餐桌这种具体物品发现搬迁障碍。只借用调查问题，不把其他行业案例结论移植成黄金答案。
M2 来源：Pixar与Khan Academy合作课程Obstacles，https://www.khanacademy.org/partner-content/pixar/storytelling/character/v/character-3 。本次网页正文未返回，可核查的搜索索引摘录涉及人物想要什么及障碍；仅作有限方法线索，未冒称完整看过课程。适用于选择故事形式时：从人物行动、阻力和选择写出变化，避免让每个人物轮流说完整道理。不强迫所有作品写剧情。
本轮操作：
研究——从材料抓具体选择与反常细节，区分原文观察和自己的解释；遇到信息不足时写出缺的具体问题，允许返回来源，别只列“缺品牌/缺SKU”。
方向——先比较内容能提供什么，再讨论制作可行性。每条构想都要有可读的开头和实际展开，空泛的“讲人性/做悦己/谈工艺”不够比较。解释经营主体如何持续获得这类观察，未知的能力不能冒称已经拥有。
创作——选题可以是信息发现、意见、情景、观察或其他适合的形式。让具体材料改变内容；不要先选一个好听的道理，再拼人物证明它。保留矛盾和人物各自理由，不要求皆大欢喜、道德收束或固定反转。
编辑——从观众实际读到的内容检查：有哪些新信息/好笑或意外的时刻/说透的关系？移除身份自报后，主体贡献在哪里？如果只能靠补“很有共鸣”“容易传播”解释好看，返回选题。不给自己评分，不宣布爆款或营销效果通过。
这些是本次可追溯的方法尝试，需要真实输出验证。它们不是八个模块、评审门禁或通用模板。
