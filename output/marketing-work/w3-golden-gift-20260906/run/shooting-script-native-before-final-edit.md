# 拍摄脚本：一份没打开的道谢礼

> 本片全部情节为虚构演绎，非真实客户案例。画面左下角全程显示"虚构演绎"标识。

## 基本参数

| 项目 | 内容 |
|---|---|
| 选题 | 一份没打开的道谢礼 |
| 形式 | 竖屏口播+桌面道具演绎 |
| 预估时长 | 约88秒（按约3字/秒+停顿估算，待试讲确认） |
| 配乐 | 无配乐版本，全程不用音乐 |
| 画面比例 | 竖屏 9:16 |
| 拍摄人数 | 一位授权讲述者（经营者本人）分次完成，无需第二人 |

## 道具清单

- 手机1部（兼拍摄）
- 手机支架1个（俯拍用）
- 普通合盖无标礼盒1个（全程不打开）
- 空白纸片若干
- 笔1支
- 桌面1张
- 暖色灯光

## 拍摄分次安排

全部内容由一位授权讲述者分次完成：

### 第一批：人脸镜头（镜1、镜6、镜7）
- 手机固定于桌面高度，讲述者面对镜头录制。
- 这三镜是讲述者本人直接说话，需面对镜头。
- 录制顺序建议：镜1 → 镜6 → 镜7。

### 第二批：桌面手部镜头（镜2、镜3、镜4、镜5）
- 手机切换到俯拍支架，俯拍桌面。
- 讲述者双手入画操作道具，手部不露脸。
- 礼盒全程合盖，不打开，不展示任何实物内容。
- 录制顺序建议：镜2（推礼盒）→ 镜3（手放盒盖）→ 镜4（拿走礼盒、写字）→ 镜5（纸片在桌上）。

### 第三批：画外音录制（镜2-镜5台词）
- 录完桌面手部镜头后，补录全部画外音。
- 讲述者一人分饰小林和老周两个声音，分别录制。
- 小林声线自然、略快；老周声线稍压低、沉稳。
- 录制后对口型剪辑到桌面画面上。

## 逐镜脚本

### 镜1（0-11s）业务主体+钩子
- 画面：讲述者半身近景，直视镜头。
- 台词："我是做黄金礼品的。但我今天想说的，不是哪款好看，是送礼之前最该想的一件事。"
- 字幕："我是做黄金礼品的"单独停留1-2秒，建立业务主体识别。
- 口播字数：约32字。

### 镜2（11-27s）抛情境
- 画面：硬切桌面俯拍，合盖礼盒放在桌上，一只手轻推礼盒到画面中央。
- 台词（画外音）："小林入职半年，同事老周帮她扛过一个难项目。她买了一份很重的礼物，盒都没开，直接放老周桌上说：'周哥，谢谢你。'"
- 声音：礼盒推桌面声。
- 画面左下角："虚构演绎"。
- 字幕："盒都没开，直接放老周桌上"。
- 口播字数：约46字。

### 镜3（27-41s）收礼者说清顾虑
- 画面：桌面俯拍，手放在礼盒盖上没动。
- 台词（画外音）："老周没碰盒子，说：'你先收回去。我帮你是同事之间的事。你送这么重的东西，我以后帮你反而不自在了。'"
- 声音："你先收回去"后停顿1秒。
- 字幕："'我以后帮你反而不自在了'"。
- 口播字数：约40字。

### 镜4（41-54s）送礼者做可见调整
- 画面：桌面俯拍，手把合盖礼盒拿走，翻出一张空白纸，拿起笔写了几行字。
- 台词（画外音）："小林愣了一下，把礼盒收回来。她翻出一张纸，写了几行字：'谢谢你帮我扛过来了。'递给老周。"
- 声音：笔触纸面声。
- 口播字数：约36字。

### 镜5（54-62s）双方具体回应
- 画面：桌面俯拍，写好的纸片在桌上。
- 台词（画外音）："老周看完，说：'这个我收。'他笑了笑，把纸片夹进了笔记本里。"
- 声音：翻纸声。
- 口播字数：约22字。

### 镜6（62-76s）讲述者收束+可用办法
- 画面：硬切回讲述者近景，直视镜头。
- 台词："贵不贵不是最重要的。先弄清对方在意什么，再决定送什么——这是我做这行一直在提醒自己的事。"
- 字幕："先弄清对方在意什么，再决定送什么"。
- 口播字数：约38字。

### 镜7（76-88s）结尾提问
- 画面：讲述者近景，直视镜头。
- 台词："你有没有送过一份对方其实不需要的好意？"
- 声音：末句后停顿2秒。
- 字幕：末句放大居中。
- 口播字数：约17字。

口播总字数：约231字。

## 配音指导

- 全程口语，温和偏慢，像跟朋友讲一件你注意到的事。
- 镜2-镜5为桌面镜头配画外音，讲述者一人分饰小林和老周两个声音，分次录制。
- 小林声线自然、略快；老周声线稍压低、沉稳。同一人分别录制后对口型剪辑。
- 镜1、镜6、镜7为讲述者本人面对镜头说话，与镜2-5的画外音分次拍摄。
- 镜6"先弄清对方在意什么，再决定送什么"是全片核心句，语速放慢，字字清楚。

## 声音设计（无配乐版，可直接执行）

- 全程不用音乐。
- 环境声：极低底噪（室内安静感）。
- 道具声：镜2礼盒推桌面声；镜4笔触纸面声；镜5翻纸声。音量低于人声。
- 无配乐版即为完整可发布版本，不依赖任何外部音源。

## 剪辑节奏

- 全片硬切，无转场特效。人脸↔桌面交替。
- 字幕：关键句出现时同步显示，镜1"我是做黄金礼品的"单独停留强化主体识别。

"你有没有送过一份对方其实不需要的好意？"——讲述者可在评论区分享观察，后续内容可回应常见情况。

## 业务主体识别

- 镜1开门见山："我是做黄金礼品的"——在片中直接说出业务背景。
- 镜6收束："这是我做这行一直在提醒自己的事"——体现"先弄清对方需要再选物"的工作方式，不宣称从业年限或亲历客户。
- 不提品牌名、店铺地址、产品链接、私信服务。

## 未验证判断标记

- 小林、老周及全部情节为虚构演绎，非真实客户案例。
- "先弄清对方在意什么，再决定送什么"是讲述者工作主张，不是学术结论或行业普遍规律。
- 老周的顾虑和回应是虚构情节，不证明"贵重礼物一定带来负担"——故事展示的是一种情况和一种调整方式。
- 88秒为预估值，待实际试讲确认。
- 评论能否引发互动未知，传播效果未知。
- 讲述者身份待经营者实际确认和授权出镜。
